Главное не нарушать структуру проекта, [оставлять комметарии](##Коментарии) и не нарушать синтаксис языка!

## Кодекс поведения

Будьте уважительны к другим участникам. Оскорбления, токсичное поведение и дискриминация недопустимы.

## С чего начать

1. Сделайте форк репозитория на GitHub.
2. Склонируйте свой форк:
   ```bash
   git clone https://github.com/Xomagat/FABSharp.git
   cd <project-name>
   ```
3. Добавьте upstream-репозиторий, чтобы синхронизироваться с основной веткой:
   ```bash
   git remote add upstream https://github.com/Xomagat/FABSharp.git
   ```
4. Посмотрите список [issues](https://github.com/Xomagat/FABSharp/issues?reload=1) — метка `help wanted` отлично подходит для первого вклада.

## Требования к окружению

Для сборки и отладки ЯП потребуется:
 - C++20 (Clang/GCC)
 - CMake

## Коментарии
В начале вашего нового файла нужно написать комментарий:
``` c++
//
// Created by (Your real name or nickname) on date (day.mouth.year)
//
```
На этом важные комментарии заканчиваются. Дальше вы оставляете комментарии когда хотите пояснить что делает определенная функция, класс, условие или цикл.

## Коммиты и сообщения

Используйте понятные сообщения коммитов, желательно в формате:

```
краткое описание

Более подробное объяснение при необходимости — что и почему
изменено, а не как (это видно из diff).
```
 - Только обязательно коммит должен соответствовать измененному файлу!
Пример:
```
fix double-free in page frame allocator
```
