## Hello World
``` c++
writeln "Hello World!";
```
 - Также есть команда write, альтернатива writeln только без переноса строки.
``` c++
write "Hello World!\n";
```

 - **Код может меняться, так что это не постоянно!**

## Типизация
|Тип|Размер|Диапозон/Описание| Пример   |
|---|---|---|---|
| `int` | 32 бит | −2 147 483 648 … 2 147 483 647 | `int x = 42;` |
| `double` | 64 бит | ~15–17 значимых цифр | `double d = 3.14159;` |
| `bool` | — | `true` / `false` | `bool b = true;` |
| `string` | — | Строка символов | `string s = "Hello";` |

 - Язык только разрабатывается! *Имена* или *кол-во* типов может **измениться**!

## Условия
``` c++
if contition
{
    // body
}
else
{
    // body
}
```

 - В условиях не обязательны скобки.
 - Также стоит заметить пока не поддерживается команды else if!

### Пример использования:
``` c++
int x = 15;

if x == 15
{
    writeln "true";
}
else
{
    writeln "false";
}
```

 - Условные операторы: ==, !=, <, >, <=, >=, &&(и) и ||(или).

## Арифметика
| Оператор | Описание                      | Пример        |
|-----|-------------------------------|---------------|
| `+` | Оператор сложения             | `4 + 2 == 6`  |
| `-` | Оператор вычитания            | `4 - 2 == 2`  |
| `*` | Оператор умножения            | `4 * 2 == 8`  |
| `/` | Оператор деления              | `4 / 2 == 2`  |
| `^` | Оператор возведения в степень | `4 ^ 2 == 16` |
