## Знакомство

FAB# — компилируемый язык программирования, написанный на C++ с использованием LLVM. Ты пишешь программу в файле `.fab`, компилятор превращает её в обычный исполняемый файл, и дальше она запускается сама по себе, без интерпретатора и лишних зависимостей.

Идея простая: минимум церемоний. Нет обязательных заголовков и «магических» шаблонов — открыл файл, написал строчку, получил программу. А когда программа вырастет, в языке найдутся функции, классы с наследованием, модули и библиотеки.

| Что | Как |
|---|---|
| Расширение файлов | `.fab` |
| Версия языка | 0.3 |
| Платформы | Windows и Linux (x86-64) |
| Результат компиляции | самостоятельный исполняемый файл |
| Точка входа | функция `main` или код прямо в файле |
| Конец команды | `;` |
| Блоки кода | `{ ... }` |
| Комментарии | `// строка` и `/* блок */` |

## Быстрый старт

Три шага от пустой папки до работающей программы:

1. Создай файл `hello.fab` с кодом из примера ниже.
2. Скомпилируй его в терминале: `fab hello.fab`
3. Запусти результат: `./hello` на Linux или `hello.exe` на Windows.

```cpp
writeln "Hello, World!";
```

Исполняемый файл появится рядом с исходником. Промежуточный объектный файл компилятор удалит сам.

### Параметры компилятора

```
fab [параметры] файл.fab
```

| Параметр | Что делает |
|---|---|
| `-h`, `--help` | показывает справку |
| `-v`, `--version` | показывает версию |
| `-o <файл>` | имя результата |
| `-O0` `-O1` `-O2` `-O3` | уровень оптимизации (по умолчанию `-O2`) |
| `-Os`, `-Oz` | оптимизация по размеру |
| `-c` | только скомпилировать в объектный файл, без линковки |
| `-S` | сохранить ассемблер (`.s`) |
| `--emit-llvm` | сохранить LLVM IR (`.ll`) |
| `--check` | только проверить синтаксис |
| `-r`, `--run` | запустить программу после сборки |
| `--keep-obj` | не удалять объектный файл после линковки |
| `--cpu=<имя>` | целевой процессор (по умолчанию `x86-64-v3`) |
| `-V`, `--verbose` | показывать этапы сборки |

Например, `fab -r hello.fab` соберёт и сразу запустит программу, а `fab --check hello.fab` быстро проверит, нет ли ошибок в синтаксисе.

> [!TIP]
> Хочешь, чтобы программа была «настоящей», с функцией `main`? Загляни в раздел [Функции](#функции). Но для коротких скриптов она не нужна: код можно писать прямо в файле, он выполнится сверху вниз.

## Вывод на экран

Для вывода есть две команды. Они почти близнецы, отличаются одним: переводом строки.

| Команда | Поведение |
|---|---|
| `writeln` | печатает значение и переходит на новую строку |
| `write` | печатает значение и остаётся на той же строке |

```cpp
write "Hello, ";
write "World!\n";
writeln "Bye!";
```

Результат:

```
Hello, World!
Bye!
```

### Что умеет печатать

| Значение | Пример | Что увидишь |
|---|---|---|
| целое число | `writeln 42;` | `42` |
| дробное число | `writeln 0.5;` | `0.5` (до 17 значащих цифр, лишние нули не печатаются) |
| логическое | `writeln true;` | `true` (и `false`) |
| символ | `writeln 'A';` | `A` |
| строка | `writeln "Привет";` | `Привет` |
| список | `writeln [1, 2];` | `[1, 2]` |
| словарь | `writeln d;` | `{a: 1, b: 2}` |

Объекты своих классов и библиотечные типы (`file`, `date`, `time`) напрямую не печатаются: выводи их поля или результат метода (`d.to_str()`).

> [!NOTE]
> Дробные числа печатаются с максимальной точностью: `double` — до 17 значащих цифр, `float` — до 9, `long double` — до 21. Поэтому `writeln 4.0;` выведет `4`, а `writeln 3.14;` может показать `3.1400000000000001` — это особенность двоичного представления, а не ошибка.

### Спецсимволы в строках и символах

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\r` | возврат каретки |
| `\"` | кавычка внутри строки |
| `\'` | апостроф внутри символа |

### Комментарии

Всё, что компилятору знать не нужно, можно спрятать в комментарий:

```cpp
// Однострочный комментарий

/*
   А этот может занимать
   сколько угодно строк
*/
writeln "Комментарии не мешают коду";
```

## Переменные и типы

Переменная — это коробочка с именем, в которой лежит значение. Тип коробочки задаётся один раз при создании.

| Тип | Размер | Что хранит | Пример |
|---|---|---|---|
| `int` | 32 бита | целые числа от −2 147 483 648 до 2 147 483 647 | `int x = 42;` |
| `long` | 64 бита | очень большие целые | `long big = 100;` |
| `short` | 16 бит | небольшие целые | `short s = 7;` |
| `double` | 64 бита | дробные числа (около 15–17 значащих цифр) | `double d = 3.14159;` |
| `float` | 32 бита | дробные числа поменьше точностью | `float f = 1.5;` |
| `long double` | 80 бит | дробные числа повышенной точности (x87) | `long double e = 1.5L;` |
| `bool` | 1 бит | `true` или `false` | `bool ready = true;` |
| `char` | 8 бит | один символ | `char c = 'a';` |
| `string` | — | текст | `string name = "FAB#";` |
| `list<T>` | — | список значений типа `T` | `list<int> nums = [1, 2, 3];` |
| `dict<K,V>` | — | словарь «ключ → значение» | `dict<string, int> ages = {"Anna": 20};` |
| `auto` | — | тип берётся из значения справа | `auto n = 5;` |
| `void` | — | «ничего»: только как тип результата функции | `define f() -> void` |

Кроме них есть типы, которые ты объявляешь сам ([классы](#классы)), и типы библиотек: `file` из `io`, `date` и `time` из `date`.

### Создание и присваивание

```cpp
int age = 20;
double pi = 3.14159;
string name = "FAB#";
bool ready = true;
char grade = 'A';
int color = #FF8800;    // шестнадцатеричное число начинается с #
int counter;            // без значения: внутри будет 0

age = 21;               // новое значение
age += 1;               // age стала 22
```

Сокращённые формы присваивания:

| Запись | Равносильно |
|---|---|
| `x += 5;` | `x = x + 5;` |
| `x -= 5;` | `x = x - 5;` |
| `x *= 5;` | `x = x * 5;` |
| `x /= 5;` | `x = x / 5;` |
| `x %= 5;` | `x = x % 5;` |

> [!NOTE]
> Если создать числовую или логическую переменную без значения, она получит нулевое значение (`0` или `false`), а список или словарь — станут пустыми. Со строками так лучше не делать: всегда давай им начальное значение, например `string s = "";`.

### auto

Если тип очевиден из значения, его можно не писать. Компилятор определит тип сам:

```cpp
auto n = 5;                 // int
auto pi = 3.14;             // double
auto big = 10L;             // long
auto name = "fab".to_upper();   // string
```

У `auto` обязательно должно быть начальное значение: `auto x;` и `auto x = null;` не сработают.

### Константы

Слово `const` делает значение неизменным. Константе обязательно нужно сразу дать значение. Константами могут быть только простые типы (`int`, `double`, `bool`, `string` и т. п.), но не списки и словари.

```cpp
const int MAX_PLAYERS = 4;
writeln MAX_PLAYERS;      // 4

// MAX_PLAYERS = 10;      // ошибка компиляции: нельзя менять константу
```

### Числа разных типов дружат

Если положить дробное число в целую переменную (или наоборот), компилятор сам всё преобразует:

```cpp
double d = 5;      // станет 5
int n = 3.99;      // станет 3: дробная часть отбрасывается, без округления
```

Для явных преобразований у каждого типа есть методы `to_int()`, `to_double()` и другие, см. [Методы типов](#методы-типов).

### Виды значений в коде

| Что | Как выглядит | Примеры |
|---|---|---|
| целое число | цифры | `0`, `42`, `1000` |
| число с разделителями | `_` между цифрами | `1_000_000` |
| дробное число | цифры с точкой | `3.14`, `0.5` |
| число с порядком | `e` или `E` | `1e6`, `2.5e-3` |
| шестнадцатеричное | `#` и цифры/буквы a–f | `#FF`, `#1a2b` |
| логическое | ключевые слова | `true`, `false` |
| символ | в одинарных кавычках | `'a'`, `'\n'` |
| строка | в двойных кавычках | `"Hello"` |
| список | значения в квадратных скобках | `[1, 2, 3]` |
| словарь | пары `ключ: значение` в фигурных скобках | `{"a": 1, "b": 2}` |
| пустое значение | ключевое слово | `null` (превращается в ноль нужного типа или в пустой список/словарь) |

### Суффиксы чисел

Без суффикса целое число это `int` (если не помещается — `long`), а дробное — `double`. Чтобы задать тип явно, допиши букву:

| Суффикс | Тип | Пример |
|---|---|---|
| `s` | `short` | `7s` |
| `L` | `long` (для целых) | `10000000000L` |
| `f` | `float` | `1.5f` |
| `d` | `double` | `2d` |
| `L` | `long double` (для дробных) | `1.5L` |

```cpp
long double e = 2.718281828459045235L;
float f = 0.1f;
writeln size_of(7s);    // 2
```

> [!NOTE]
> Литерал словаря понимает, какого он типа, только когда его кладут в переменную с явным типом: `dict<string, int> d = {"a": 1};`. Литерал списка с элементами можно использовать и сам по себе (`[1, 2, 3].sum()`), а пустой список `[]` требует явного типа: `list<int> a = [];`.

### Где «живёт» переменная

Переменная, созданная внутри `{ ... }`, исчезает за закрывающей скобкой.

```cpp
int x = 1;
if x == 1
{
    int y = 2;           // y видна только внутри этих скобок
    writeln x + y;       // 3
}
```

### Глобальные переменные

Переменные, объявленные на верхнем уровне (вне функций и классов), глобальные: их видно из любой функции.

```cpp
int counter = 0;

define hit()
{
    counter += 1;
}

hit();
hit();
writeln counter;     // 2
```

Если перед объявлением написать `static`, переменная будет видна только в своём файле. Это удобно в модулях, чтобы внутренние данные не конфликтовали с чужими именами (см. [Подключение своего файла](#подключение-своего-файла)):

```cpp
static int secret = 42;     // доступна только в этом файле
```

Повторно объявить глобальную переменную с тем же именем нельзя. Если в файле есть `main`, значения глобальных переменных вычисляются в самом начале `main`.

## Операторы

### Арифметика

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (целое на целое даёт целое) |
| `/` | деление | `7.0 / 2` | `3.5` |
| `%` | остаток от деления | `7 % 2` | `1` |

Когда в выражении встречаются и целые, и дробные числа, результат становится дробным. Из двух целых типов результат берётся по более широкому.

Строки умеют складываться: так они склеиваются.

```cpp
string greeting = "Hello, " + "World!";
writeln greeting;        // Hello, World!
```

Чтобы приклеить к строке число, сначала превращай его в строку:

```cpp
int n = 5;
writeln "n = " + n.to_str();    // n = 5
```

Унарные операторы: `-x` меняет знак, `+x` ничего не делает, `!flag` переворачивает логическое значение.

### Сравнение

| Оператор | Смысл |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

Символы сравниваются так же, как числа: `c == 'a'`, `c >= '0'`. Строки через `==` и `<` сравнивать нельзя: используй `compare()` и `equals_ignore_case()`.

### Логика

| Оператор | Смысл | Пример |
|---|---|---|
| `&&` | И: верно, если верны обе части | `x > 0 && x < 10` |
| `\|\|` | ИЛИ: верно, если верна хотя бы одна часть | `x < 0 \|\| x > 10` |
| `!` | НЕ: переворачивает значение | `!ready` |

Вычисление «ленивое»: если ответ уже ясен по левой части, правая даже не вычисляется.

### Приоритет операторов

От самого сильного к самому слабому:

| Уровень | Операторы |
|---|---|
| 1 | унарные `-`, `+`, `!` |
| 2 | `*`, `/`, `%` |
| 3 | `+`, `-` |
| 4 | `<`, `>`, `<=`, `>=` |
| 5 | `==`, `!=` |
| 6 | `&&` |
| 7 | `\|\|` |

Не уверен в порядке? Расставь скобки: `(a + b) * c`.

> [!WARNING]
> Оператора возведения в степень `^` в версии 0.3 нет. Для степеней используй функцию `pow` из библиотеки `math`. Операторов `++` и `--` тоже пока нет, пиши `i += 1;`.

## Условия

Классическое «если... иначе»:

```cpp
int x = 15;

if x == 15
{
    writeln "ровно пятнадцать";
}
else
{
    writeln "что-то другое";
}
```

Если вариантов больше двух, цепляй `else if`:

```cpp
int score = 72;

if score >= 90
{
    writeln "отлично";
}
else if score >= 60
{
    writeln "хорошо";
}
else
{
    writeln "надо подтянуть";
}
```

Несколько правил:

- Скобки вокруг условия **не обязательны**: можно `if x > 5`, можно `if (x > 5)`.
- Условия можно объединять: `if x > 0 && x < 10`.
- Число тоже работает как условие: `0` означает «ложь», всё остальное «истина».
- Если в ветке одна команда, фигурные скобки можно опустить.

## Циклы

| Цикл | Когда использовать |
|---|---|
| `while` | повторять, пока верно условие |
| `do-while` | то же, но тело выполнится минимум один раз |
| `for` | когда известно, сколько раз повторять |

> [!IMPORTANT]
> В циклах скобки вокруг условия **обязательны**, в отличие от `if`.

### while

```cpp
int i = 0;
while (i < 3)
{
    writeln i;
    i += 1;
}
```

Результат: `0`, `1`, `2`.

### do-while

Сначала действие, потом проверка. Поэтому тело выполнится хотя бы раз, даже если условие с самого начала ложное:

```cpp
int i = 10;
do
{
    writeln i;
    i += 1;
} while (i < 5);
```

Результат: `10`. Обрати внимание на `;` после закрывающей скобки условия.

### for

Три части в скобках: что сделать перед стартом, когда продолжать, что делать после каждого шага.

```cpp
for (int i = 1; i <= 5; i += 1)
{
    writeln i;
}
```

Результат: `1`, `2`, `3`, `4`, `5`.

Так удобно обходить списки:

```cpp
list<string> names = ["Аня", "Боря", "Вика"];
for (int i = 0; i < names.length(); i += 1)
{
    writeln names[i];
}
```

### break и continue

| Команда | Что делает |
|---|---|
| `break;` | немедленно выходит из цикла |
| `continue;` | пропускает остаток шага и идёт к следующему |

```cpp
int i = 0;
while (true)
{
    i += 1;
    if i % 2 == 0 { continue; }   // чётные пропускаем
    if i > 7 { break; }           // после 7 выходим
    writeln i;
}
```

Результат: `1`, `3`, `5`, `7`.

> [!TIP]
> В цикле `for` команда `continue` не застрянет навечно: она перейдёт к шагу `i += 1`, а не прямо к проверке условия.

## Функции

Функция — это именованный кусок кода, который можно вызывать сколько угодно раз.

```cpp
define имя(тип аргумент1, тип аргумент2) -> типРезультата
{
    // тело
}
```

- `define` объявляет функцию.
- Тип результата пишется после стрелки `->`. Если стрелки нет, функция ничего не возвращает (`void`).
- Результат отдаётся командой `return`.
- В аргументах и результате можно использовать любые типы, в том числе `list<int>`, `dict<string, int>`, свои классы и типы библиотек.

### Функция без результата

```cpp
define greet(string name)
{
    writeln "Hello, " + name + "!";
}

greet("FAB#");        // Hello, FAB#!
```

### Функция с результатом

```cpp
define square(int x) -> int
{
    return x * x;
}

writeln square(7);    // 49
```

Если тело состоит из одной команды, фигурные скобки не нужны:

```cpp
define twice(int x) -> int
    return x * 2;
```

### Значения по умолчанию

Аргументу можно задать значение по умолчанию. Тогда его разрешается не передавать при вызове. Такие аргументы идут в конце списка:

```cpp
define greet(string name, string hello = "Привет")
{
    writeln hello + ", " + name + "!";
}

greet("Аня");               // Привет, Аня!
greet("Боря", "Здорово");   // Здорово, Боря!
```

Нельзя поставить обычный аргумент после аргумента со значением по умолчанию.

### Рекурсия

Функция может вызывать сама себя:

```cpp
define factorial(int n) -> int
{
    if n <= 1 { return 1; }
    return n * factorial(n - 1);
}

writeln factorial(5);    // 120
```

### Перегрузка

Можно создать несколько функций с одним именем, если у них разные типы аргументов. Компилятор сам выберет подходящую:

```cpp
define show(int x)
{
    writeln x;
}

define show(string s)
{
    writeln "текст: " + s;
}

show(5);          // 5
show("hi");       // текст: hi
```

> [!WARNING]
> Типы аргументов при вызове твоей функции должны совпадать с объявлением точно. Если есть только `square(int x)`, то вызов `square(2.5)` не сработает: `2.5` это `double`. Объяви версию `square(double x)` или передай `int`. Для функций библиотек действует послабление: если точного совпадения нет, компилятор подбирает ближайшую версию с наименьшим числом преобразований (поэтому `sin(1)` работает). Если таких версий несколько и они равноценны, будет ошибка `Ambiguous call`.

### Функция main

Есть два способа написать программу:

| Способ | Как это выглядит |
|---|---|
| Без `main` | команды лежат прямо в файле и выполняются сверху вниз |
| С `main` | вся программа живёт внутри `main`, как в больших языках |

```cpp
define main() -> int
{
    writeln "Hello from main!";
    return 0;
}
```

`return 0;` в конце `main` писать необязательно: если забыл, компилятор вернёт `0` сам.

> [!IMPORTANT]
> Если в файле есть `main`, снаружи неё можно оставлять только объявления: функции (`define`), классы и глобальные переменные. Обычные команды вроде `writeln` должны жить внутри функций. Функции нужно объявлять **выше** того места, где их вызываешь (классы можно и ниже).

## Ввод данных

Команда `input_in` читает значение с клавиатуры прямо в переменную. Переменную нужно создать заранее.

```cpp
int n;
write "Введи число: ";
input_in n;
writeln n * 2;
```

Что можно вводить:

| Тип переменной | Что читается |
|---|---|
| `int`, `short`, `long` | целое число |
| `float`, `double` | дробное число (через точку) |
| `bool` | число: `0` — `false`, любое другое — `true` |
| `char` | один символ (пробелы и переводы строк перед ним пропускаются) |
| `string` | одно слово до первого пробела |

> [!NOTE]
> Целую строку с пробелами через `input_in` прочитать нельзя. Для этого подключи библиотеку `console` и вызови `console.read_line()` (см. [console](#console)). Списки и словари через `input_in` не вводятся.

## Методы типов

У значений есть **методы** — маленькие функции, которые вызываются через точку: `значение.метод(аргументы)`. Методы работают и на переменных, и на литералах, и их можно соединять в цепочки:

```cpp
string s = "  fab#  ";
writeln s.trim().to_upper();      // FAB#
writeln 'x'.to_upper();           // X
writeln "42".to_int() + 1;        // 43
```

## Списки

Список хранит последовательность значений одного типа. Элементами могут быть `int`, `long`, `short`, `char`, `float`, `double`, `string` и `bool`.

```cpp
list<int> nums = [5, 2, 9];
nums.addend(7);                // добавить в конец
nums.sort();

writeln nums;                  // [2, 5, 7, 9]
writeln nums.length();         // 4
writeln nums[0];               // 2
writeln nums.sum();            // 23

nums[0] = 100;                 // записать элемент
```

Пустой список создаётся без значения, через `null` или через `[]`:

```cpp
list<string> words;
words.addend("раз");
words.addend("два");
writeln words.join(", ");      // раз, два

list<int> empty = [];
```

> [!TIP]
> Не пиши `>` и `=` слитно, когда закрываешь тип: `list<int>= ...` лексер прочитает как `>=`. Ставь пробел или сразу имя переменной: `list<int> nums = ...`.

> [!IMPORTANT]
> Методы списка никогда не падают из-за неверного номера: `get(100)` на коротком списке вернёт «нулевое» значение типа (`0`, `false` или пустую строку), а `set`, `insert` и `remove_at` с неверным номером просто ничего не делают. Но запись и чтение через квадратные скобки (`nums[i]`, `nums[i] = x`) границы **не проверяют**: неверный номер приведёт к чтению или порче чужой памяти. Если номер может выйти за границы, используй `get` и `set`.

### Методы списка

| Метод | Результат | Что делает |
|---|---|---|
| `addend(x)` | — | добавляет `x` **в конец** |
| `add(x)` | — | добавляет `x` **в начало** |
| `insert(i, x)` | — | вставляет `x` на позицию `i` |
| `extend(other)` | — | дописывает в конец все элементы другого списка |
| `length()` | `int` | количество элементов |
| `empty()` | `bool` | список пуст? |
| `capacity()`, `reserve(n)` | `int` / — | ёмкость и резервирование места |
| `get(i)`, `set(i, x)` | `T` / — | прочитать / записать элемент |
| `first()`, `last()` | `T` | первый и последний элемент |
| `remove_at(i)` | — | удаляет элемент с позиции `i` |
| `remove(x)` | `bool` | удаляет первое `x`; `true`, если нашёл |
| `pop()`, `pop_first()` | `T` | достаёт и удаляет последний / первый |
| `clear()` | — | очищает список |
| `contains(x)` | `bool` | есть ли `x` |
| `index_of(x)` | `int` | позиция первого `x` или `-1` |
| `count(x)` | `int` | сколько раз встречается `x` |
| `reverse()` | — | переворачивает на месте |
| `swap(i, j)` | — | меняет два элемента местами |
| `sort()`, `sort_desc()` | — | сортировка по возрастанию / убыванию |
| `min()`, `max()` | `T` | наименьший / наибольший |
| `sum()` | `T` | сумма (у строк — склейка); для `char` и `bool` недоступна |
| `copy()` | `list<T>` | независимая копия |
| `slice(start, length)` | `list<T>` | кусок списка |
| `join(sep)` | `string` | склеивает элементы в строку через разделитель |

## Словари

Словарь хранит пары «ключ → значение» и помнит порядок, в котором ключи были добавлены. Ключами могут быть `int`, `long`, `short`, `char` и `string`, значениями — `int`, `long`, `short`, `char`, `float`, `double`, `string` и `bool`.

```cpp
dict<string, int> ages = {"Аня": 20, "Боря": 31};
ages.set("Вика", 25);

writeln ages.get("Аня");          // 20
writeln ages.get_or("Дима", -1);  // -1
writeln ages.contains("Боря");    // true
writeln ages.length();            // 3
writeln ages;                     // {Аня: 20, Боря: 31, Вика: 25}
```

Для словарей с числовыми ключами и ключами-символами значение можно прочитать и через квадратные скобки: `d[5]` делает то же самое, что `d.get(5)`. Для строковых ключей скобки пока не работают, используй `get`. Записать значение через скобки нельзя, для этого есть `set`.

Литерал `{...}` понимает, какого он типа, только при создании переменной с явным типом `dict<K, V>`. Пустой словарь создаётся без значения: `dict<int, string> d;`.

Чтобы пройтись по всем парам, используй `key_at` и `value_at`:

```cpp
for (int i = 0; i < ages.length(); i += 1)
{
    writeln ages.key_at(i) + ": " + ages.value_at(i).to_str();
}
```

### Методы словаря

| Метод | Результат | Что делает |
|---|---|---|
| `set(k, v)` | — | добавляет пару или заменяет значение у существующего ключа |
| `merge(other)` | — | переносит в словарь все пары другого словаря |
| `get(k)` | `V` | значение по ключу; если ключа нет, «нулевое» значение типа |
| `get_or(k, def)` | `V` | значение по ключу или `def`, если ключа нет |
| `key_at(i)`, `value_at(i)` | `K` / `V` | ключ / значение по порядковому номеру |
| `contains(k)` | `bool` | есть ли ключ |
| `contains_value(v)` | `bool` | есть ли значение |
| `length()`, `empty()`, `capacity()` | `int` / `bool` | размер |
| `remove(k)` | `bool` | удаляет пару; `true`, если ключ был |
| `pop(k)` | `V` | удаляет пару и возвращает её значение |
| `clear()` | — | очищает словарь |
| `keys()`, `values()` | `list<K>` / `list<V>` | списки ключей и значений |
| `copy()` | `dict<K,V>` | независимая копия |

## Классы

Класс собирает вместе данные (поля) и действия над ними (методы). Из класса создаются объекты.

```cpp
class Counter
{
private:
    int value;

public:
    Counter(int start)
    {
        this.value = start;
    }

    define inc()
    {
        this.value = this.value + 1;
    }

    define get() -> int
    {
        return this.value;
    }
}

Counter c = new Counter(10);
c.inc();
c.inc();
writeln c.get();       // 12
delete c;
```

### Из чего состоит класс

| Часть | Как пишется | Что это |
|---|---|---|
| поле | `int value;` | переменная внутри объекта |
| метод | `define имя(...) -> тип { ... }` | функция объекта |
| конструктор | `Имя(аргументы) { ... }` | выполняется при создании |
| деструктор | `~Имя() { ... }` | выполняется при `delete` |
| статический метод | `static define имя(...) { ... }` | вызывается у самого класса |
| видимость | `private:` / `public:` | кто может пользоваться следующими полями и методами |

Видимость действует до следующей метки. До первой метки всё `private`. К закрытым полям и методам можно обращаться только изнутри самого класса, снаружи будет ошибка компиляции.

### Создание и удаление объектов

```cpp
Counter a = new Counter(5);    // объект с конструктором
Counter b;                     // создать объект, конструктор без аргументов вызовется, если он есть
Counter c = null;              // пока никакого объекта

delete a;                      // вызвать деструктор и освободить память
```

После `delete` переменная становится `null`. Память объектов автоматически **не** освобождается: если объект больше не нужен, удали его сам. Списки, словари и библиотечные типы, лежащие в полях класса, освобождаются деструктором автоматически.

### Поля, методы и this

Поле читается через точку: `c.value` (если оно `public`). Внутри метода к полям своего объекта можно обратиться просто по имени, но менять поле, а также вызывать другие методы своего объекта, нужно через `this`:

```cpp
define reset()
{
    this.value = 0;        // запись только через this
    this.inc();            // вызов метода своего объекта
}
```

Поля-строки по умолчанию равны `""`, поля-списки и поля-словари создаются пустыми, остальные равны нулю.

> [!WARNING]
> В версии 0.3 присваивание вида `value = 5;` или `value += 1;` по голому имени внутри метода поле не меняет. Всегда пиши `this.value = ...`. Составные операторы (`+=`, `-=`) для полей через точку тоже пока не работают: пиши `this.value = this.value + 1;`.

### Наследование

Класс может унаследовать поля и методы другого класса: `class Дочерний : Родитель`. Если у родителя есть конструктор с аргументами, дочерний обязан вызвать его после двоеточия:

```cpp
class Animal
{
public:
    string name;

    Animal(string n)
    {
        this.name = n;
    }

    define speak()
    {
        writeln this.name + " издаёт звук";
    }
}

class Dog : Animal
{
public:
    Dog(string n) : Animal(n)
    {
    }

    define speak()
    {
        writeln this.name + ": гав!";
    }
}

Animal a = new Dog("Рекс");
a.speak();             // Рекс: гав!
delete a;
```

Методы виртуальные: переменная типа `Animal` с объектом `Dog` вызовет метод `Dog`. При переопределении метода тип результата менять нельзя. Из тела конструктора родительский конструктор можно вызвать и командой `super(аргументы);`.

### Статические методы

Статический метод принадлежит самому классу и вызывается без объекта:

```cpp
class MathUtil
{
public:
    static define twice(int x) -> int
    {
        return x * 2;
    }
}

writeln MathUtil.twice(21);    // 42
```

### Методы с одним именем

Методы, как и функции, можно перегружать по типам аргументов. Типы аргументов при вызове метода должны совпадать с объявлением точно.

### Пустые ссылки

Если вызвать метод или обратиться к полю у переменной со значением `null`, программа напечатает сообщение `Null reference: ...` и завершится с кодом 1.

> [!NOTE]
> Объект нельзя напечатать целиком через `writeln`. Сравнивать переменные с `null` через `==` пока тоже нельзя.

## Библиотеки и модули

### Подключение библиотеки

Команда `use` подключает библиотеку. Подключать нужно **до** первого использования её функций и типов.

```cpp
use math;

writeln sqrt(16.0);    // 4
writeln pow(2, 10);    // 1024
writeln floor(3.7);    // 3
writeln round(2.5);    // 3
writeln PI;            // 3.1415926535897931
```

Доступные библиотеки:

| Библиотека | Что в ней |
|---|---|
| `math` | математика |
| `random` | случайные числа |
| `io` | файлы и работа с путями |
| `system` | запуск программ, аргументы, окружение, папки |
| `date` | даты и время |
| `console` | цвета, очистка экрана, чтение строк |

Можно подключить несколько: `use io; use system;`.

### math

Константы: `PI`, `TAU`, `E`, `PHI`, `SQRT2`, `LN2`, `LN10` (все `double`).

Функции выбираются по типам аргументов: `pow(2, 10)` посчитает целое число, а `pow(2.0, 10.0)` дробное. Это та же перегрузка, что и у твоих функций.

| Группа | Функции | Аргументы → результат |
|---|---|---|
| Модуль | `abs(x)` | `int`, `long`, `double` → тот же тип |
| | `fabs(x)` | `float`, `double` → тот же тип |
| Степени и корни | `pow(x, n)` | `int`, `long`, `float`, `double` → тот же тип (целая степень с отрицательным `n` даёт `0`) |
| | `sqrt(x)` | `int` → `double`; `float` → `float`; `double` → `double` |
| | `cbrt(x)` | `float`, `double` → тот же тип |
| | `hypot(a, b)` | `float`, `double` → тот же тип |
| Округление | `ceil(x)`, `floor(x)`, `round(x)`, `trunc(x)` | `float`, `double` → тот же тип |
| Остаток | `fmod(a, b)` | `float`, `double` → тот же тип (знак как у `a`) |
| | `mod(a, b)` | `int` → `int` (знак как у `b`) |
| Тригонометрия | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh` | `float`, `double` → тот же тип |
| | `atan2(y, x)` | `float`, `double` → тот же тип |
| Экспонента и логарифмы | `exp`, `log`, `log2`, `log10` | `float`, `double` → тот же тип |
| | `log(x, base)` | `double, double` → `double` |
| Мин., макс. | `min(a, b)`, `max(a, b)` | `int`, `long`, `float`, `double` → тот же тип |
| | `clamp(x, lo, hi)` | `int`, `long`, `float`, `double` → тот же тип |
| | `sign(x)` | `int`, `long`, `float`, `double` → `int` (`-1`, `0`, `1`) |
| Целые числа | `gcd(a, b)`, `lcm(a, b)` | `int`, `long` → тот же тип |
| | `factorial(n)` | `int` → `long` (для `n < 0` или `n > 20` даёт `-1`) |
| | `is_prime(n)` | `int`, `long` → `bool` |
| Проверки | `is_nan(x)`, `is_inf(x)`, `is_finite(x)` | `float`, `double` → `bool` |
| | `inf()`, `nan()` | → `double` |
| Углы | `to_rad(x)`, `to_deg(x)` | `float`, `double` → тот же тип |
| Интерполяция | `lerp(a, b, t)` | `float`, `double` → тот же тип |

> [!TIP]
> Если точной версии функции под типы аргументов нет, компилятор подбирает ближайшую: `sin(1)` и `exp(2)` работают, хотя аргумент целый.

### random

Генератор случайных чисел. По умолчанию он стартует от текущего времени, поэтому при каждом запуске числа разные. Чтобы получить повторяемую последовательность, задай зерно.

| Функция | Результат | Что делает |
|---|---|---|
| `set_seed(n)` | — | задаёт зерно генератора |
| `randi(a, b)` | `int` | случайное целое от `a` до `b` **включительно** |
| `rands(a, b)` | `short` | то же для `short` |
| `randl(a, b)` | `long` | то же для `long` |
| `randf(a, b)` | `float` | случайное дробное в промежутке от `a` до `b` |
| `randd(a, b)` | `double` | то же для `double` |

```cpp
use random;

set_seed(42);
writeln randi(1, 6);       // бросок кубика
writeln randd(0.0, 1.0);
```

### io

Работа с файлами. Есть два способа: короткие функции, которым нужен только путь, и тип `file` для пошагового чтения и записи.

**Функции для путей**

| Функция | Результат | Что делает |
|---|---|---|
| `file_exists(path)` | `bool` | файл существует? |
| `file_size(path)` | `long` | размер в байтах, `-1` при ошибке |
| `file_read(path)` | `string` | всё содержимое файла (при ошибке пустая строка) |
| `file_write(path, text)` | `bool` | записывает текст, перезаписывая файл |
| `file_append(path, text)` | `bool` | дописывает текст в конец |
| `file_lines(path)` | `list<string>` | строки файла |
| `file_delete(path)` | `bool` | удаляет файл |
| `file_rename(from, to)` | `bool` | переименовывает |
| `io_error()` | `string` | текст последней ошибки |

```cpp
use io;

file_write("notes.txt", "первая\nвторая\n");
list<string> lines = file_lines("notes.txt");
writeln lines.length();      // 2
```

**Тип file**

Файл открывается функцией `file_open(путь, режим)`. Режимы такие же, как в языке C: `"r"` чтение, `"w"` запись с очисткой, `"a"` дописывание, `"rb"`, `"wb"` и другие. Если открыть файл не получилось, объект окажется «закрытым»: проверь это методом `is_open()`, а причину узнай через `io_error()`.

```cpp
use io;

file f = file_open("log.txt", "w");
if (!f.is_open())
{
    writeln io_error();
}
else
{
    f.putln("запись 1");
    f.putln("запись 2");
    f.close();
}
delete f;
```

Готовые стандартные потоки: `file_stdin()`, `file_stdout()`, `file_stderr()`.

| Метод | Результат | Что делает |
|---|---|---|
| `close()` | `bool` | закрывает файл |
| `is_open()` | `bool` | файл открыт? |
| `eof()` | `bool` | дальше читать нечего? (true сразу после прочтения последней строки) |
| `flush()` | `bool` | сбрасывает буфер на диск |
| `path()`, `mode()` | `string` | путь и режим |
| `get_line()` | `string` | следующая строка без перевода строки |
| `get_char()` | `char` | следующий символ (`'\0'` в конце) |
| `read(n)` | `string` | до `n` байт |
| `read_all()` | `string` | всё до конца файла |
| `lines()` | `list<string>` | все оставшиеся строки |
| `put(s)`, `putln(s)` | `bool` | записывает строку (`putln` ещё и переводит строку) |
| `put_char(c)` | `bool` | записывает символ |
| `size()` | `long` | размер файла |
| `tell()` | `long` | текущая позиция |
| `seek(pos)` | `bool` | перейти на позицию от начала |
| `rewind()` | — | вернуться в начало |

Читать файл построчно удобно так:

```cpp
file f = file_open("notes.txt", "r");
while (!f.eof())
{
    writeln f.get_line();
}
delete f;
```

`delete f;` закрывает файл, если он ещё открыт, и освобождает память. Для стандартных потоков `delete` безопасен и ничего не делает.

| Функция | Результат | Что делает |
|---|---|---|
| `system(cmd)` | `int` | выполняет команду, возвращает код завершения |
| `system_output(cmd)` | `string` | выполняет команду и возвращает всё, что она напечатала |
| `exit(code)` | — | завершает программу с кодом |
| `abort()` | — | аварийно завершает программу |
| `arg_count()` | `int` | сколько аргументов командной строки (включая имя программы) |
| `arg(i)` | `string` | аргумент номер `i` (`arg(0)` — имя программы) |
| `args()` | `list<string>` | все аргументы списком |
| `get_env(name)` | `string` | переменная окружения (пустая строка, если нет) |
| `has_env(name)` | `bool` | переменная окружения задана? |
| `set_env(name, value)` | `bool` | задаёт переменную окружения |
| `sleep(sec)`, `sleep_ms(ms)` | — | пауза в секундах / миллисекундах |
| `ticks_ms()` | `long` | монотонный таймер в миллисекундах (для замера времени работы кода) |

| `chdir(path)`, `mkdir(path)`, `rmdir(path)` | `bool` | сменить, создать, удалить папку |
| `is_dir(path)` | `bool` | это папка? |

```cpp
use system;

long start = ticks_ms();
sleep_ms(250);
writeln ticks_ms() - start;     // около 250

for (int i = 1; i < arg_count(); i += 1)
    writeln arg(i);
```

### date

Библиотека вводит два типа: `date` (календарная дата) и `time` (время суток с точностью до секунды). Объекты создаются функциями и освобождаются через `delete`.

**«Сейчас»** (читаются как переменные, без скобок):

| Переменная | Что это |
|---|---|
| `year_now`, `month_now`, `day_now` | текущие год, месяц, день |
| `hour_now`, `min_now`, `sec_now` | текущие час, минута, секунда |
| `weekday_now` | день недели: 1 — понедельник, 7 — воскресенье |
| `yday_now` | номер дня в году |
| `unix_now` | секунды с 1 января 1970 (`long`) |

**Создание** (при неверных значениях вернётся «пустой» объект, методы которого безопасны и дают нули и пустые строки):

| Функция | Что делает |
|---|---|
| `date_new(y, m, d)` | дата из года, месяца и дня |
| `date_now()` | сегодняшняя дата |
| `date_parse("2026-11-01")` | дата из строки `ГГГГ-ММ-ДД` |
| `date_from_days(n)` | дата по числу дней от 1 января 1970 |
| `date_valid(y, m, d)` | `bool`: существует ли такая дата |
| `time_new(h, m, s)` | время из часов, минут, секунд |
| `time_now()` | текущее время |
| `time_parse("23:30:15")` | время из строки `ЧЧ:ММ:СС` или `ЧЧ:ММ` |
| `time_from_seconds(n)` | время по числу секунд с полуночи |

**Методы date**

| Метод | Результат | Что делает |
|---|---|---|
| `year()`, `month()`, `day()` | `int` | части даты |
| `weekday()` | `int` | 1 — понедельник ... 7 — воскресенье |
| `day_of_year()`, `days_in_month()` | `int` | номер дня в году, число дней в месяце |
| `is_leap()` | `bool` | високосный год? |
| `to_days()` | `long` | дни от 1 января 1970 |
| `month_name()`, `weekday_name()` | `string` | названия по-английски, строчными буквами |
| `add_days(n)`, `add_months(n)`, `add_years(n)` | — | сдвигает дату **на месте** |
| `copy()` | `date` | независимая копия |
| `diff_days(other)` | `long` | сколько дней между датами (`this - other`) |
| `compare(other)` | `int` | `-1`, `0` или `1` |
| `equals(other)`, `is_before(other)`, `is_after(other)` | `bool` | сравнение |
| `to_str()` | `string` | `ГГГГ-ММ-ДД` |
| `format(f)` | `string` | форматирование по шаблону |

Шаблон `format` для даты: `%Y` год, `%y` две цифры года, `%m` месяц, `%d` день, `%j` день года, `%B` название месяца, `%A` день недели.

**Методы time**

| Метод | Результат | Что делает |
|---|---|---|
| `hour()`, `minute()`, `second()` | `int` | части времени |
| `to_seconds()` | `int` | секунды от полуночи |
| `add_seconds(n)`, `add_minutes(n)`, `add_hours(n)` | — | сдвигает время **на месте** (через полночь переходит по кругу) |
| `copy()` | `time` | независимая копия |
| `diff_seconds(other)` | `int` | разница в секундах |
| `compare(other)`, `equals(other)`, `is_before(other)`, `is_after(other)` | `int` / `bool` | сравнение |
| `to_str()` | `string` | `ЧЧ:ММ:СС` |
| `format(f)` | `string` | шаблон: `%H` часы, `%M` минуты, `%S` секунды |

```cpp
use date;

date d = date_new(2026, 11, 1);
d.add_days(30);
writeln d.to_str();               // 2026-12-01
writeln d.format("%d.%m.%Y");     // 01.12.2026
writeln d.weekday_name();         // tuesday

time t = time_new(23, 30, 0);
t.add_minutes(45);
writeln t.to_str();               // 00:15:00

writeln year_now;
delete d;
delete t;
```

> [!NOTE]
> `add_months` не вылезает за конец месяца: `31 января + 1 месяц` даст `28` (или `29`) февраля.

### console

Библиотека `console` состоит из **статических** функций: они вызываются как `console.имя(...)`. Цвета задаются ANSI-кодами; на Windows компилятор включает их поддержку сам.

| Вызов | Результат | Что делает |
|---|---|---|
| `console.error(s)`, `console.errorln(s)` | — | печатает в поток ошибок (без перевода / с переводом строки) |
| `console.flush()` | — | сбрасывает буфер вывода |
| `console.read_line()` | `string` | читает всю строку (с пробелами) |
| `console.read_char()` | `char` | читает один символ |
| `console.clear()` | — | очищает экран |
| `console.color(c)` | — | включает цвет текста |
| `console.reset()` | — | сбрасывает цвет |
| `console.beep()` | — | звуковой сигнал |
| `console.title(s)` | — | заголовок окна терминала |

Константы цветов: `color_grey`, `color_red`, `color_green`, `color_yellow`, `color_blue`, `color_purple`, `color_cyan`, `color_white` (числа от 0 до 7).

```cpp
use console;

console.color(color_green);
writeln "Готово!";
console.reset();

write "Как тебя зовут? ";
string name = console.read_line();
writeln "Привет, " + name + "!";
```

### Подключение своего файла

Большую программу можно разложить по файлам. Чтобы подтянуть другой `.fab`-файл, укажи путь в кавычках:

```cpp
use "libs/helpers.fab";
```

Компилятор ищет файл сначала рядом с твоей программой, а потом рядом с самим компилятором. Каждый файл подключается один раз, даже если написать `use` несколько раз.

Подключённые файлы делят общее пространство имён: их функции, классы и глобальные переменные видны во всей программе. Если нужна переменная, невидимая за пределами файла, объяви её со словом `static`:

```cpp
// counter.fab
static int hits = 0;        // доступна только в counter.fab

define count() -> int
{
    hits += 1;
    return hits;
}
```

## Низкоуровневые возможности

### size_of

`size_of(тип)` или `size_of(значение)` возвращает размер в байтах (результат типа `long`):

```cpp
writeln size_of(int);        // 4
writeln size_of(long);       // 8
writeln size_of(3.5);        // 8
```

### type

`type(значение)` возвращает название типа значения как строку:

```cpp
list<int> a = [1, 2];
writeln type(a);             // list<int>
writeln type(1.5f);          // float
```

### asm

Встроенный ассемблер (синтаксис AT&T). Первый аргумент — код, второй — ограничения LLVM, дальше идут значения:

```cpp
asm("nop");
```

Если нужны ограничения и значения, их дописывают через запятую: `asm("код", "ограничения", значение1, значение2);`.

Эта возможность предназначена для опытных пользователей: компилятор не проверяет, что ты написал.

## Мини-проект: FizzBuzz

Пора собрать всё вместе. Классическая задача: пройти числа от 1 до 15 и вывести `Fizz` для кратных 3, `Buzz` для кратных 5 и `FizzBuzz` для кратных обоим.

```cpp
for (int i = 1; i <= 15; i += 1)
{
    if i % 15 == 0
    {
        writeln "FizzBuzz";
    }
    else if i % 3 == 0
    {
        writeln "Fizz";
    }
    else if i % 5 == 0
    {
        writeln "Buzz";
    }
    else
    {
        writeln i;
    }
}
```

Здесь в одной программе работают цикл `for`, цепочка `else if`, остаток от деления `%` и вывод.

**Попробуй сам:**

- Измени границу цикла и сделай FizzBuzz до 100.
- Вынеси проверку в функцию `define label(int n) -> string` и верни из неё нужное слово.
- Выведи сумму всех чисел от 1 до 100 с помощью цикла и переменной-накопителя.
- Сложи ответы FizzBuzz в `list<string>` и выведи их одной строкой через `join(" ")`.
- Запиши результат в файл с помощью библиотеки `io`.
- Оберни логику в класс `FizzBuzz` со статическим методом `label`.

| Класс | `class A { public: int x; A(int v) { this.x = v; } }` |
| Наследование | `class B : A { ... }` |
| Создать / удалить объект | `A a = new A(1);` / `delete a;` |
| Статический вызов | `Класс.метод(...)` |
| Глобальная переменная файла | `static int x = 0;` |
| Подключить библиотеку | `use math;` |
| Подключить файл | `use "путь/файл.fab";` |
| Комментарии | `// ...` и `/* ... */` |

## Частые ошибки

Компилятор сообщает об ошибках на английском (с приставкой `Compile error:`). Вот что они значат:

| Сообщение | Что случилось | Как исправить |
|---|---|---|
| `You miss the ;` | забыта точка с запятой | добавь `;` в конце команды |
| `Variable {x} not found!` | переменная не объявлена или вышла из области видимости | объяви её выше или внутри нужных скобок |
| `Cannot assign to const variable 'x'!` | попытка изменить константу | убери `const` или не меняй значение |
| `Cannot assign to library const 'X'!` | попытка изменить константу библиотеки (`PI`, `INT_MAX`...) | константы библиотек менять нельзя |
| `Library variable 'x' is read-only!` | попытка присвоить значение «сейчас»-переменной (`year_now`...) | они только читаются |
| `Cannot declare a variable of type 'void'!` | переменная типа `void` | выбери настоящий тип |
| `'auto' needs an initializer: auto x = ...;` | у `auto` нет значения (или оно `null`) | задай начальное значение |
| `Global 'x' is already defined!` | глобальная переменная объявлена дважды | используй другое имя |
| `'break' outside of a loop!` | `break` вне цикла | используй его только внутри циклов |
| `'continue' outside of a loop!` | `continue` вне цикла | то же самое |
| `Unknown function or overload for codegen: name(...)` | такой функции нет, либо типы аргументов не подходят | проверь имя, `use` и типы аргументов (в скобках показаны переданные типы) |
| `Ambiguous call to 'name'` | под вызов подходит несколько функций библиотеки одинаково хорошо | приведи аргументы к нужному типу явно (`to_double()` и т. п.) |
| `Parameter without default value after parameter with default!` | обычный аргумент после аргумента со значением | поставь аргументы со значениями в конец |
| `Type 'X' has no method 'name'` | у типа нет такого метода | сверься с таблицами в разделе «Методы типов» |
| `Type 'X' has no method 'name' with these arguments` | метод есть, но с другими аргументами | проверь количество и типы аргументов |
| `Class 'X' has no method 'name' with these arguments` | у класса нет такого метода (или аргументы не совпали точно) | проверь имя и типы |
| `Method 'name' is private!` / `Field 'x' of class 'X' is private!` | обращение к закрытому члену снаружи класса | добавь `public:` или обращайся изнутри |
| `Class 'X' has no field 'name'!` | такого поля нет | проверь имя поля |
| `Unknown parent class 'X'!` | наследуешься от несуществующего класса | проверь имя |
| `Class 'X' has no constructor!` | передаёшь аргументы в `new` у класса без конструктора | добавь конструктор или убери аргументы |
| `Wrong argument count for constructor of 'X'!` | не то число аргументов в `new` | сверься с объявлением конструктора |
| `Constructor of 'P' takes N argument(s): write ': P(...)' ...` | у родителя есть конструктор с аргументами | вызови его после двоеточия |
| `Override of 'm' changes return type!` | у переопределённого метода другой тип результата | верни тот же тип |
| `Destructor name must match class name!` | имя после `~` не совпало с классом | напиши `~ИмяКласса()` |
| `Cannot print an object of class 'X'` | попытка напечатать объект | печатай его поля |
| `Cannot delete a value of type 'X'!` | `delete` для значения обычного типа | `delete` работает с объектами, списками, словарями и типами библиотек |
| `'static' at top level must be followed by a variable declaration!` | `static` перед чем-то, кроме переменной | `static` можно ставить только перед объявлением глобальной переменной |
| `Library '...' not found!` | нет файла библиотеки | проверь имя в `use` и папку `lib` рядом с компилятором |
| `Module '...' not found ...` | не найден файл из `use "..."` | проверь путь: ищется рядом с программой и рядом с компилятором |
| `Token ... does not match ...` | на месте нужного символа стоит другой | чаще всего забыта скобка, например в `while` |
| `Unknown expression!` | компилятор не понял выражение | проверь опечатки и лишние символы |
| `Unknown type for codegen: ...` | такого типа нет | проверь название типа (например, `byte` не существует) |
| `null has no standalone value` | `null` использован не в присваивании (например, `x == null`) | сравнения с `null` пока не поддерживаются |
| `Dict literal needs a type context: dict<K,V> x = {...};` | словарь `{...}` написан не в объявлении переменной | сначала объяви `dict<K, V> x = {...};` |
| `Empty list literal needs a type context: list<T> x = [];` | пустой `[]` без типа | объяви `list<T> x = [];` |
| `List literal can only initialize a list<T>!` | список `[...]` положили в переменную другого типа | объяви переменную как `list<T>` |
| `List literal has mixed element types: ...` | в списке вперемешку разные типы | приведи элементы к одному типу |
| `Type '...' does not support indexing!` | квадратные скобки у типа, который их не поддерживает | индексировать можно списки, строки и словари (чтение) |
| `Cannot assign by index to type '...'!` | запись `d[k] = v` у словаря | используй `d.set(k, v)` |
| `Only '+' is supported for strings!` | со строкой использован не `+` | строки умеют только склеиваться |
| `Unsupported type for input_in codegen!` | `input_in` для списка, словаря или другого типа | вводи значения по одному |
| `Link failed!` | не получилось собрать исполняемый файл | проверь, что рядом с компилятором лежат папки `lib` и `tools` |

Во время работы программы возможна ошибка `Null reference: ...`: ты обратился к полю или методу объекта, которого нет (`null`).

## Чего пока нет

Версия 0.3 это ещё не конец пути. Пока не поддерживаются:

- оператор возведения в степень `^` (используй `pow` из `math`);
- операторы `++` и `--`;
- сравнение строк через `==` и `<` (используй `compare()` и `equals_ignore_case()`);
- сравнение с `null` (`x == null`);
- склейка строки с числом или символом (`"x = " + 5`, используй `5.to_str()`);
- запись в словарь через `d[key] = x` (используй `d.set(key, x)`) и чтение `d["строка"]` по строковому ключу (используй `d.get("строка")`);
- вложенные списки и словари (`list<list<int>>`);
- составные присваивания для полей (`obj.x += 1`);
- значения по умолчанию у аргументов методов (у обычных функций они есть);
- тип `byte`;
- ввод целой строки через `input_in` (есть `console.read_line()`);
- свои шаблоны (generics).

## Известные проблемы

- Строки печатаются как есть через системный `printf`, поэтому символ `%` внутри выводимой строки пока может дать странный результат. Избегай `%` в тексте для `write` и `writeln`.
- Команда `write` без перевода строки корректно работает со строками, `int`, `double`, `float`, `bool` и списками. Для `char`, `long` и словарей используй `writeln`.
- Присваивание полю по голому имени внутри метода (`value = 5;`) ничего не меняет, пиши `this.value = 5;`.
- Чтение и запись по номеру через квадратные скобки не проверяет границы списка.
- `find(char)` возвращает неверный результат, если символа в строке нет; для надёжного поиска используй `find` со строкой (`s.find("x")`).
- `substr` с неверными границами возвращает пустой указатель вместо строки.
- Память строк, списков и словарей автоматически не освобождается. Для коротких программ это не страшно, а в долгих циклах освобождай ненужные списки и словари командой `delete`.
