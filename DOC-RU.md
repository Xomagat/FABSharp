## Знакомство

FAB# — компилируемый язык программирования, написанный на C++ с использованием LLVM. Ты пишешь программу в файле `.fab`, компилятор превращает её в обычный исполняемый файл, и дальше она запускается сама по себе, без интерпретатора и лишних зависимостей.

Идея простая: минимум церемоний. Нет обязательных заголовков, классов и «магических» шаблонов — открыл файл, написал строчку, получил программу.

| Что | Как |
|---|---|
| Расширение файлов | `.fab` |
| Версия языка | 0.2 |
| Платформы | Windows и Linux (x86-64) |
| Результат компиляции | самостоятельный исполняемый файл |
| Точка входа | функция `main` или код прямо в файле |
| Конец команды | `;` |
| Блоки кода | `{ ... }` |
| Комментарии | `// строка` и `/* блок */` |

## Быстрый старт

Три шага от пустой папки до работающей программы:

1. Создай файл `hello.fab` с кодом из примера ниже.
2. Скомпилируй его в терминале: `fab hello.fab`
3. Запусти результат: `./hello` на Linux или `hello.exe` на Windows.

```cpp
writeln "Hello, World!";
```

Исполняемый файл появится рядом с исходником. Промежуточный объектный файл компилятор удалит сам.

Параметры компилятора:

| Команда | Что делает |
|---|---|
| `fab файл.fab` | компилирует программу |
| `fab --help` или `fab -h` | показывает справку |
| `fab --version` или `fab -v` | показывает версию |

> [!TIP]
> Хочешь, чтобы программа была «настоящей», с функцией `main`? Загляни в раздел [Функции](#функции). Но для коротких скриптов она не нужна: код можно писать прямо в файле, он выполнится сверху вниз.

## Вывод на экран

Для вывода есть две команды. Они почти близнецы, отличаются одним: переводом строки.

| Команда | Поведение |
|---|---|
| `writeln` | печатает значение и переходит на новую строку |
| `write` | печатает значение и остаётся на той же строке |

```cpp
write "Hello, ";
write "World!\n";
writeln "Bye!";
```

Результат:

```
Hello, World!
Bye!
```

### Что умеет печатать

| Значение | Пример | Что увидишь |
|---|---|---|
| целое число | `writeln 42;` | `42` |
| дробное число | `writeln 0.5;` | `0.5` (до 17 значащих цифр, лишние нули не печатаются) |
| логическое | `writeln true;` | `1` (а `false` напечатается как `0`) |
| символ | `writeln 'A';` | `A` |
| строка | `writeln "Привет";` | `Привет` |
| список | `writeln [1, 2];` | см. [Списки](#списки) |
| словарь | `writeln d;` | см. [Словари](#словари) |

> [!NOTE]
> Дробные числа печатаются с максимальной точностью: `double` — до 17 значащих цифр, `float` — до 9. Поэтому `writeln 4.0;` выведет `4`, а `writeln 3.14;` может показать `3.1400000000000001` — это особенность двоичного представления, а не ошибка. Чтобы напечатать логическое значение словами, используй `flag.to_str()`.

### Спецсимволы в строках и символах

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\r` | возврат каретки |
| `\"` | кавычка внутри строки |
| `\'` | апостроф внутри символа |

### Комментарии

Всё, что компилятору знать не нужно, можно спрятать в комментарий:

```cpp
// Однострочный комментарий

/*
   А этот может занимать
   сколько угодно строк
*/
writeln "Комментарии не мешают коду";
```

## Переменные и типы

Переменная — это коробочка с именем, в которой лежит значение. Тип коробочки задаётся один раз при создании.

| Тип | Размер | Что хранит | Пример |
|---|---|---|---|
| `int` | 32 бита | целые числа от −2 147 483 648 до 2 147 483 647 | `int x = 42;` |
| `long` | 64 бита | очень большие целые | `long big = 100;` |
| `short` | 16 бит | небольшие целые | `short s = 7;` |
| `double` | 64 бита | дробные числа (около 15–17 значащих цифр) | `double d = 3.14159;` |
| `float` | 32 бита | дробные числа поменьше точностью | `float f = 1.5;` |
| `bool` | 1 бит | `true` или `false` | `bool ready = true;` |
| `char` | 8 бит | один символ | `char c = 'a';` |
| `string` | — | текст | `string name = "FAB#";` |
| `list<T>` | — | список значений типа `T` | `list<int> nums = [1, 2, 3];` |
| `dict<K,V>` | — | словарь «ключ → значение» | `dict<string, int> ages = {"Anna": 20};` |
| `void` | — | «ничего»: только как тип результата функции | `define f() -> void` |

### Создание и присваивание

```cpp
int age = 20;
double pi = 3.14159;
string name = "FAB#";
bool ready = true;
char grade = 'A';
int color = #FF8800;    // шестнадцатеричное число начинается с #
int counter;            // без значения: внутри будет 0

age = 21;               // новое значение
age += 1;               // age стала 22
```

Сокращённые формы присваивания:

| Запись | Равносильно |
|---|---|
| `x += 5;` | `x = x + 5;` |
| `x -= 5;` | `x = x - 5;` |
| `x *= 5;` | `x = x * 5;` |
| `x /= 5;` | `x = x / 5;` |
| `x %= 5;` | `x = x % 5;` |

> [!NOTE]
> Если создать числовую или логическую переменную без значения, она получит нулевое значение (`0` или `false`), а список или словарь — станут пустыми. Со строками так лучше не делать: всегда давай им начальное значение, например `string s = "";`.

### Константы

Слово `const` делает значение неизменным. Константе обязательно нужно сразу дать значение. Константами могут быть только простые типы (`int`, `double`, `bool`, `string` и т. п.), но не списки и словари.

```cpp
const int MAX_PLAYERS = 4;
writeln MAX_PLAYERS;      // 4

// MAX_PLAYERS = 10;      // ошибка компиляции: нельзя менять константу
```

### Числа разных типов дружат

Если положить дробное число в целую переменную (или наоборот), компилятор сам всё преобразует:

```cpp
double d = 5;      // станет 5
int n = 3.99;      // станет 3: дробная часть отбрасывается, без округления
```

Для явных преобразований у каждого типа есть методы `to_int()`, `to_double()` и другие, см. [Методы типов](#методы-типов).

### Виды значений в коде

| Что | Как выглядит | Примеры |
|---|---|---|
| целое число | цифры | `0`, `42`, `1000` |
| дробное число | цифры с точкой | `3.14`, `0.5` |
| шестнадцатеричное | `#` и цифры/буквы a–f | `#FF`, `#1a2b` |
| логическое | ключевые слова | `true`, `false` |
| символ | в одинарных кавычках | `'a'`, `'\n'` |
| строка | в двойных кавычках | `"Hello"` |
| список | значения в квадратных скобках | `[1, 2, 3]` |
| словарь | пары `ключ: значение` в фигурных скобках | `{"a": 1, "b": 2}` |
| пустое значение | ключевое слово | `null` (превращается в ноль нужного типа или в пустой список/словарь) |

> [!NOTE]
> Литералы списка и словаря понимают, какого они типа, только когда их кладут в переменную с явным типом: `list<int> a = [1, 2];`. Сам по себе `[1, 2]` не получится передать, например, в функцию.

### Где «живёт» переменная

Переменная, созданная внутри `{ ... }`, исчезает за закрывающей скобкой.

```cpp
int x = 1;
if x == 1
{
    int y = 2;           // y видна только внутри этих скобок
    writeln x + y;       // 3
}
```

## Операторы

### Арифметика

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (целое на целое даёт целое) |
| `/` | деление | `7.0 / 2` | `3.5` |
| `%` | остаток от деления | `7 % 2` | `1` |

Когда в выражении встречаются и целые, и дробные числа, результат становится дробным.

Строки умеют складываться: так они склеиваются.

```cpp
string greeting = "Hello, " + "World!";
writeln greeting;        // Hello, World!
```

Чтобы приклеить к строке число, сначала превращай его в строку:

```cpp
int n = 5;
writeln "n = " + n.to_str();    // n = 5
```

Унарные операторы: `-x` меняет знак, `+x` ничего не делает, `!flag` переворачивает логическое значение.

### Сравнение

| Оператор | Смысл |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

Символы сравниваются так же, как числа: `c == 'a'`, `c >= '0'`.

### Логика

| Оператор | Смысл | Пример |
|---|---|---|
| `&&` | И: верно, если верны обе части | `x > 0 && x < 10` |
| `\|\|` | ИЛИ: верно, если верна хотя бы одна часть | `x < 0 \|\| x > 10` |
| `!` | НЕ: переворачивает значение | `!ready` |

Вычисление «ленивое»: если ответ уже ясен по левой части, правая даже не вычисляется.

### Приоритет операторов

От самого сильного к самому слабому:

| Уровень | Операторы |
|---|---|
| 1 | унарные `-`, `+`, `!` |
| 2 | `*`, `/`, `%` |
| 3 | `+`, `-` |
| 4 | `<`, `>`, `<=`, `>=` |
| 5 | `==`, `!=` |
| 6 | `&&` |
| 7 | `\|\|` |

Не уверен в порядке? Расставь скобки: `(a + b) * c`.

> [!WARNING]
> Оператора возведения в степень `^` в версии 0.2 нет. Для степеней используй функцию `pow` из библиотеки `math`: [Библиотеки и модули](#библиотеки-и-модули). Операторов `++` и `--` тоже пока нет, пиши `i += 1;`.

## Условия

Классическое «если... иначе»:

```cpp
int x = 15;

if x == 15
{
    writeln "ровно пятнадцать";
}
else
{
    writeln "что-то другое";
}
```

Если вариантов больше двух, цепляй `else if`:

```cpp
int score = 72;

if score >= 90
{
    writeln "отлично";
}
else if score >= 60
{
    writeln "хорошо";
}
else
{
    writeln "надо подтянуть";
}
```

Несколько правил:

- Скобки вокруг условия **не обязательны**: можно `if x > 5`, можно `if (x > 5)`.
- Условия можно объединять: `if x > 0 && x < 10`.
- Число тоже работает как условие: `0` означает «ложь», всё остальное «истина».
- Если в ветке одна команда, фигурные скобки можно опустить.

## Циклы

| Цикл | Когда использовать |
|---|---|
| `while` | повторять, пока верно условие |
| `do-while` | то же, но тело выполнится минимум один раз |
| `for` | когда известно, сколько раз повторять |

> [!IMPORTANT]
> В циклах скобки вокруг условия **обязательны**, в отличие от `if`.

### while

```cpp
int i = 0;
while (i < 3)
{
    writeln i;
    i += 1;
}
```

Результат: `0`, `1`, `2`.

### do-while

Сначала действие, потом проверка. Поэтому тело выполнится хотя бы раз, даже если условие с самого начала ложное:

```cpp
int i = 10;
do
{
    writeln i;
    i += 1;
} while (i < 5);
```

Результат: `10`. Обрати внимание на `;` после закрывающей скобки условия.

### for

Три части в скобках: что сделать перед стартом, когда продолжать, что делать после каждого шага.

```cpp
for (int i = 1; i <= 5; i += 1)
{
    writeln i;
}
```

Результат: `1`, `2`, `3`, `4`, `5`.

Так удобно обходить списки:

```cpp
list<string> names = ["Аня", "Боря", "Вика"];
for (int i = 0; i < names.length(); i += 1)
{
    writeln names[i];
}
```

### break и continue

| Команда | Что делает |
|---|---|
| `break;` | немедленно выходит из цикла |
| `continue;` | пропускает остаток шага и идёт к следующему |

```cpp
int i = 0;
while (true)
{
    i += 1;
    if i % 2 == 0 { continue; }   // чётные пропускаем
    if i > 7 { break; }           // после 7 выходим
    writeln i;
}
```

Результат: `1`, `3`, `5`, `7`.

> [!TIP]
> В цикле `for` команда `continue` не застрянет навечно: она перейдёт к шагу `i += 1`, а не прямо к проверке условия.

## Функции

Функция — это именованный кусок кода, который можно вызывать сколько угодно раз.

```cpp
define имя(тип аргумент1, тип аргумент2) -> типРезультата
{
    // тело
}
```

- `define` объявляет функцию.
- Тип результата пишется после стрелки `->`. Если стрелки нет, функция ничего не возвращает (`void`).
- Результат отдаётся командой `return`.
- В аргументах и результате можно использовать любые типы, в том числе `list<int>` и `dict<string, int>`.

### Функция без результата

```cpp
define greet(string name)
{
    writeln "Hello, " + name + "!";
}

greet("FAB#");        // Hello, FAB#!
```

### Функция с результатом

```cpp
define square(int x) -> int
{
    return x * x;
}

writeln square(7);    // 49
```

Если тело состоит из одной команды, фигурные скобки не нужны:

```cpp
define twice(int x) -> int
    return x * 2;
```

### Несколько аргументов

```cpp
define cool_print(string label, int value)
{
    writeln label + " готово";
    writeln value;
}

cool_print("Задача", 42);
```

### Рекурсия

Функция может вызывать сама себя:

```cpp
define factorial(int n) -> int
{
    if n <= 1 { return 1; }
    return n * factorial(n - 1);
}

writeln factorial(5);    // 120
```

### Перегрузка

Можно создать несколько функций с одним именем, если у них разные типы аргументов. Компилятор сам выберет подходящую:

```cpp
define show(int x)
{
    writeln x;
}

define show(string s)
{
    writeln "текст: " + s;
}

show(5);          // 5
show("hi");       // текст: hi
```

> [!WARNING]
> Типы аргументов при вызове должны совпадать с объявлением точно. Если есть только `square(int x)`, то вызов `square(2.5)` не сработает: `2.5` это `double`. Объяви версию `square(double x)` или передай `int`. (Для функций стандартной библиотеки действует послабление: если точного совпадения нет, компилятор пробует расширить числа до `double`, поэтому `sin(1)` работает.)

### Функция main

Есть два способа написать программу:

| Способ | Как это выглядит |
|---|---|
| Без `main` | команды лежат прямо в файле и выполняются сверху вниз |
| С `main` | вся программа живёт внутри `main`, как в больших языках |

```cpp
define main() -> int
{
    writeln "Hello from main!";
    return 0;
}
```

`return 0;` в конце `main` писать необязательно: если забыл, компилятор вернёт `0` сам.

> [!IMPORTANT]
> Если в файле есть `main`, снаружи неё можно оставлять только объявления функций (`define`). Обычные команды вроде `writeln` должны жить внутри функций. Функции нужно объявлять **выше** того места, где их вызываешь.

## Ввод данных

Команда `input_in` читает значение с клавиатуры прямо в переменную. Переменную нужно создать заранее.

```cpp
int n;
write "Введи число: ";
input_in n;
writeln n * 2;
```

Что можно вводить:

| Тип переменной | Что читается |
|---|---|
| `int`, `short`, `long` | целое число |
| `float`, `double` | дробное число (через точку) |
| `bool` | число: `0` — `false`, любое другое — `true` |
| `char` | один символ (пробелы и переводы строк перед ним пропускаются) |
| `string` | одно слово до первого пробела, максимум 255 символов |

> [!NOTE]
> Целую строку с пробелами пока прочитать нельзя. Списки и словари через `input_in` не вводятся.

## Методы типов

У значений есть **методы** — маленькие функции, которые вызываются через точку: `значение.метод(аргументы)`. Методы работают и на переменных, и на литералах, и их можно соединять в цепочки:

```cpp
string s = "  fab#  ";
writeln s.trim().to_upper();      // FAB#
writeln 'x'.to_upper();           // X
writeln "42".to_int() + 1;        // 43
```

Методы типов `string`, `char`, `bool`, `int`, `short`, `long`, `float`, `double`, `list` и `dict` подключены всегда, `use` для них не нужен. Ниже `T` — тип элемента списка, `K`/`V` — типы ключа и значения словаря.

### string

| Метод | Результат | Что делает |
|---|---|---|
| `length()` | `int` | длина строки |
| `empty()` | `bool` | строка пустая? |

## Списки

Список хранит последовательность значений одного типа. Элементами могут быть `int`, `long`, `short`, `char`, `float`, `double`, `string` и `bool`.

```cpp
list<int> nums = [5, 2, 9];
nums.addend(7);                // добавить в конец
nums.sort();

writeln nums;                  // [2, 5, 7, 9]
writeln nums.length();         // 4
writeln nums[0];               // 2
writeln nums.sum();            // 23
```

Пустой список создаётся без значения (или через `null`):

```cpp
list<string> words;
words.addend("раз");
words.addend("два");
writeln words.join(", ");      // раз, два
```

> [!TIP]
> Не пиши `>` и `=` слитно, когда закрываешь тип: `list<int>= ...` лексер прочитает как `>=`. Ставь пробел или сразу имя переменной: `list<int> nums = ...`.

> [!IMPORTANT]
> Методы списка никогда не падают из-за неверного номера: `get(100)` на коротком списке вернёт «нулевое» значение типа (`0`, `false` или пустую строку), а `set`, `insert` и `remove_at` с неверным номером просто ничего не делают. Следи за границами сам.

### Методы списка

| Метод | Результат | Что делает |
|---|---|---|
| `addend(x)` | — | добавляет `x` **в конец** |
| `add(x)` | — | добавляет `x` **в начало** |
| `insert(i, x)` | — | вставляет `x` на позицию `i` |
| `extend(other)` | — | дописывает в конец все элементы другого списка |
| `length()` | `int` | количество элементов |
| `empty()` | `bool` | список пуст? |
| `capacity()`, `reserve(n)` | `int` / — | ёмкость и резервирование места |
| `get(i)`, `set(i, x)` | `T` / — | прочитать / записать элемент |
| `first()`, `last()` | `T` | первый и последний элемент |
| `remove_at(i)` | — | удаляет элемент с позиции `i` |
| `remove(x)` | `bool` | удаляет первое `x`; `true`, если нашёл |
| `pop()`, `pop_first()` | `T` | достаёт и удаляет последний / первый |
| `clear()` | — | очищает список |

| `min()`, `max()` | `T` | наименьший / наибольший |

Читать элемент можно и через квадратные скобки: `nums[2]`.

## Словари

Словарь хранит пары «ключ → значение» и помнит порядок, в котором ключи были добавлены. Ключами могут быть `int`, `long`, `short`, `char` и `string`, значениями — `int`, `long`, `short`, `char`, `float`, `double`, `string` и `bool`.

```cpp
dict<string, int> ages = {"Аня": 20, "Боря": 31};
ages.set("Вика", 25);

writeln ages.get("Аня");          // 20
writeln ages.get_or("Дима", -1);  // -1
writeln ages.contains("Боря");    // 1
writeln ages.length();            // 3
writeln ages;                     // {Аня: 20, Боря: 31, Вика: 25}
```

Литерал `{...}` понимает, какого он типа, только при создании переменной с явным типом `dict<K, V>`. Пустой словарь создаётся без значения: `dict<int, string> d;`.

Чтобы пройтись по всем парам, используй `key_at` и `value_at`:

```cpp
for (int i = 0; i < ages.length(); i += 1)
{
    writeln ages.key_at(i) + ": " + ages.value_at(i).to_str();
}
```

### Методы словаря

| Метод | Результат | Что делает |
|---|---|---|
| `set(k, v)` | — | добавляет пару или заменяет значение у существующего ключа |
| `merge(other)` | — | переносит в словарь все пары другого словаря |
| `get(k)` | `V` | значение по ключу; если ключа нет, «нулевое» значение типа |
| `get_or(k, def)` | `V` | значение по ключу или `def`, если ключа нет |
| `key_at(i)`, `value_at(i)` | `K` / `V` | ключ / значение по порядковому номеру |
| `contains(k)` | `bool` | есть ли ключ |
| `contains_value(v)` | `bool` | есть ли значение |
| `length()`, `empty()`, `capacity()` | `int` / `bool` | размер |
| `remove(k)` | `bool` | удаляет пару; `true`, если ключ был |
| `pop(k)` | `V` | удаляет пару и возвращает её значение |
| `clear()` | — | очищает словарь |
| `keys()`, `values()` | `list<K>` / `list<V>` | списки ключей и значений |
| `copy()` | `dict<K,V>` | независимая копия |

## Библиотеки и модули

### Подключение библиотеки

Команда `use` подключает библиотеку. Подключать нужно **до** первого использования её функций.

```cpp
use math;

writeln sqrt(16.0);    // 4
writeln pow(2, 10);    // 1024
writeln floor(3.7);    // 3
writeln round(2.5);    // 3
writeln PI;            // 3.1415926535897931
```

### Библиотека math

Константы: `PI`, `TAU`, `E`, `PHI`, `SQRT2`, `LN2`, `LN10` (все `double`).

Функции выбираются по типам аргументов: `pow(2, 10)` посчитает целое число, а `pow(2.0, 10.0)` дробное. Это та же перегрузка, что и у твоих функций.

| Группа | Функции | Аргументы → результат |
|---|---|---|
| Модуль | `abs(x)` | `int`, `long`, `double` → тот же тип |
| | `fabs(x)` | `float`, `double` → тот же тип |
| Степени и корни | `pow(x, n)` | `int`, `long`, `float`, `double` → тот же тип (целая степень с отрицательным `n` даёт `0`) |
| | `sqrt(x)` | `int` → `double`; `float` → `float`; `double` → `double` |
| | `cbrt(x)` | `float`, `double` → тот же тип |
| | `hypot(a, b)` | `float`, `double` → тот же тип |
| Округление | `ceil(x)`, `floor(x)`, `round(x)`, `trunc(x)` | `float`, `double` → тот же тип |
| Остаток | `fmod(a, b)` | `float`, `double` → тот же тип (знак как у `a`) |
| | `mod(a, b)` | `int` → `int` (знак как у `b`) |
| Тригонометрия | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sinh`, `cosh`, `tanh` | `float`, `double` → тот же тип |
| | `atan2(y, x)` | `float`, `double` → тот же тип |
| Экспонента и логарифмы | `exp`, `log`, `log2`, `log10` | `float`, `double` → тот же тип |
| | `log(x, base)` | `double, double` → `double` |
| Мин., макс. | `min(a, b)`, `max(a, b)` | `int`, `long`, `float`, `double` → тот же тип |
| | `clamp(x, lo, hi)` | `int`, `long`, `float`, `double` → тот же тип |
| | `sign(x)` | `int`, `long`, `float`, `double` → `int` (`-1`, `0`, `1`) |
| Целые числа | `gcd(a, b)`, `lcm(a, b)` | `int`, `long` → тот же тип |
| | `factorial(n)` | `int` → `long` (для `n < 0` или `n > 20` даёт `-1`) |
| | `is_prime(n)` | `int`, `long` → `bool` |
| Проверки | `is_nan(x)`, `is_inf(x)`, `is_finite(x)` | `float`, `double` → `bool` |
| | `inf()`, `nan()` | → `double` |
| Углы | `to_rad(x)`, `to_deg(x)` | `float`, `double` → тот же тип |
| Интерполяция | `lerp(a, b, t)` | `float`, `double` → тот же тип |

> [!TIP]
> Если точной версии функции под типы аргументов нет, компилятор пробует расширить числа до `double`: `sin(1)` и `exp(2)` работают, хотя аргумент целый.

### Подключение своего файла

Большую программу можно разложить по файлам. Чтобы подтянуть другой `.fab`-файл, укажи путь в кавычках:

```cpp
use "libs/helpers.fab";
```

Каждый файл подключается один раз, даже если написать `use` несколько раз.

> [!NOTE]
> В версии 0.2 путь в `use "..."` отсчитывается от папки, где лежит сам компилятор, а не от папки со скриптом.

## Мини-проект: FizzBuzz

Пора собрать всё вместе. Классическая задача: пройти числа от 1 до 15 и вывести `Fizz` для кратных 3, `Buzz` для кратных 5 и `FizzBuzz` для кратных обоим.

```cpp
for (int i = 1; i <= 15; i += 1)
{
    if i % 15 == 0
    {
        writeln "FizzBuzz";
    }
    else if i % 3 == 0
    {
        writeln "Fizz";
    }
    else if i % 5 == 0
    {
        writeln "Buzz";
    }
    else
    {
        writeln i;
    }
}
```

Здесь в одной программе работают цикл `for`, цепочка `else if`, остаток от деления `%` и вывод.

**Попробуй сам:**

- Измени границу цикла и сделай FizzBuzz до 100.
- Вынеси проверку в функцию `define label(int n) -> string` и верни из неё нужное слово.
- Выведи сумму всех чисел от 1 до 100 с помощью цикла и переменной-накопителя.
- Сложи ответы FizzBuzz в `list<string>` и выведи их одной строкой через `join(" ")`.

## Частые ошибки

Компилятор сообщает об ошибках на английском (с приставкой `Compile error:`). Вот что они значат:

| Сообщение | Что случилось | Как исправить |
|---|---|---|
| `You miss the ;` | забыта точка с запятой | добавь `;` в конце команды |
| `Variable {x} not found!` | переменная не объявлена или вышла из области видимости | объяви её выше или внутри нужных скобок |
| `Cannot assign to const variable 'x'!` | попытка изменить константу | убери `const` или не меняй значение |
| `Cannot assign to library const 'X'!` | попытка изменить константу библиотеки (`PI`, `INT_MAX`...) | константы библиотек менять нельзя |
| `Cannot declare a variable of type 'void'!` | переменная типа `void` | выбери настоящий тип |
| `'break' outside of a loop!` | `break` вне цикла | используй его только внутри циклов |
| `'continue' outside of a loop!` | `continue` вне цикла | то же самое |
| `Unknown function or overload for codegen: name(...)` | такой функции нет, либо типы аргументов не подходят | проверь имя, `use` и типы аргументов (в скобках показаны переданные типы) |
| `Type 'X' has no method 'name'` | у типа нет такого метода | сверься с таблицами в разделе «Методы типов» |
| `Type 'X' has no method 'name' with these arguments` | метод есть, но с другими аргументами | проверь количество и типы аргументов |
| `Library '...' not found!` | нет файла библиотеки | проверь имя в `use` и папку `lib` рядом с компилятором |
| `Token ... does not match ...` | на месте нужного символа стоит другой | чаще всего забыта скобка, например в `while` |
| `Unknown expression!` | компилятор не понял выражение | проверь опечатки и лишние символы |
| `Unknown type for codegen: ...` | такого типа нет | проверь название типа (например, `byte` не существует) |
| `Dict literal needs a type context: dict<K,V> x = {...};` | словарь `{...}` написан не в объявлении переменной | сначала объяви `dict<K, V> x = {...};` |
| `List literal can only initialize a list<T>!` | список `[...]` положили в переменную другого типа | объяви переменную как `list<T>` |
| `Type '...' does not support indexing!` | квадратные скобки у типа, который их не поддерживает | индексировать можно списки и строки |
| `Only '+' is supported for strings!` | со строкой использован не `+` | строки умеют только склеиваться |
| `Unsupported type for input_in codegen!` | `input_in` для списка или словаря | вводи значения по одному |
| `Link failed!` | не получилось собрать исполняемый файл | проверь, что рядом с компилятором лежат папки `lib` и `tools` |

## Чего пока нет

Версия 0.2 это ещё не конец пути. Пока не поддерживаются:

- оператор возведения в степень `^` (используй `pow` из `math`);
- операторы `++` и `--`;
- сравнение строк через `==` и `<` (используй `compare()` и `equals_ignore_case()`);
- склейка строки с числом (`"x = " + 5`, используй `5.to_str()`);
- запись в элемент списка через `a[i] = x` (используй `a.set(i, x)`);
- чтение значения словаря через `d[key]` (используй `d.get(key)`);
- вложенные списки и словари (`list<list<int>>`);
- тип `byte`;
- структуры и классы;
- ввод целой строки с пробелами;
- несколько файлов с общим состоянием за пределами `use "..."`.

## Известные проблемы

- Строки печатаются как есть через системный `printf`, поэтому символ `%` внутри выводимой строки пока может дать странный результат. Избегай `%` в тексте для `write` и `writeln`.
- Команда `write` без перевода строки пока корректно работает со строками, `int`, `double` и `float`. Для `char`, `long`, списков и словарей используй `writeln`.
