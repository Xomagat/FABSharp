## Знакомство

FAB# — компилируемый язык программирования, написанный на C++. Ты пишешь программу в файле `.fab`, компилятор превращает её в обычный исполняемый файл, и дальше она запускается сама по себе, без интерпретатора и лишних зависимостей.

Идея простая: минимум церемоний. Нет обязательных заголовков, классов и «магических» шаблонов — открыл файл, написал строчку, получил программу.

| Что | Как |
|---|---|
| Расширение файлов | `.fab` |
| Версия языка | 0.1 |
| Платформы | Windows и Linux (x86-64) |
| Результат компиляции | самостоятельный исполняемый файл |
| Точка входа | функция `main` или код прямо в файле |
| Конец команды | `;` |
| Блоки кода | `{ ... }` |
| Комментарии | `// строка` и `/* блок */` |

## Быстрый старт

Три шага от пустой папки до работающей программы:

1. Создай файл `hello.fab` с кодом из примера ниже.
2. Скомпилируй его в терминале: `fab hello.fab`
3. Запусти результат: `./hello` на Linux или `hello.exe` на Windows.

```cpp
writeln "Hello, World!";
```

Исполняемый файл появится рядом с исходником. Промежуточный объектный файл компилятор удалит сам.

Параметры компилятора:

| Команда | Что делает |
|---|---|
| `fab файл.fab` | компилирует программу |
| `fab --help` или `fab -h` | показывает справку |
| `fab --version` или `fab -v` | показывает версию |

> [!TIP]
> Хочешь, чтобы программа была «настоящей», с функцией `main`? Загляни в раздел [Функции](#функции). Но для коротких скриптов она не нужна: код можно писать прямо в файле, он выполнится сверху вниз.

## Вывод на экран

Для вывода есть две команды. Они почти близнецы, отличаются одним: переводом строки.

| Команда | Поведение |
|---|---|
| `writeln` | печатает значение и переходит на новую строку |
| `write` | печатает значение и остаётся на той же строке |

```cpp
write "Hello, ";
write "World!\n";
writeln "Bye!";
```

Результат:

```
Hello, World!
Bye!
```

### Что умеет печатать

| Значение | Пример | Что увидишь |
|---|---|---|
| целое число | `writeln 42;` | `42` |
| дробное число | `writeln 3.14;` | `3.140000` (шесть знаков после точки) |
| логическое | `writeln true;` | `1` (а `false` напечатается как `0`) |
| строка | `writeln "Привет";` | `Привет` |

### Спецсимволы в строках

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\r` | возврат каретки |
| `\"` | кавычка внутри строки |

### Комментарии

Всё, что компилятору знать не нужно, можно спрятать в комментарий:

```cpp
// Однострочный комментарий

/*
   А этот может занимать
   сколько угодно строк
*/
writeln "Комментарии не мешают коду";
```

## Переменные и типы

Переменная — это коробочка с именем, в которой лежит значение. Тип коробочки задаётся один раз при создании.

| Тип | Размер | Что хранит | Пример |
|---|---|---|---|
| `int` | 32 бита | целые числа от −2 147 483 648 до 2 147 483 647 | `int x = 42;` |
| `long` | 64 бита | очень большие целые | `long big = 100;` |
| `short` | 16 бит | небольшие целые | `short s = 7;` |
| `byte` | 8 бит | совсем маленькие целые | `byte b = 1;` |
| `double` | 64 бита | дробные числа (около 15–17 значащих цифр) | `double d = 3.14159;` |
| `float` | 32 бита | дробные числа поменьше точностью | `float f = 1.5;` |
| `bool` | 1 бит | `true` или `false` | `bool ready = true;` |
| `string` | — | текст | `string name = "FAB#";` |
| `void` | — | «ничего»: только как тип результата функции | `define f() -> void` |

### Создание и присваивание

```cpp
int age = 20;
double pi = 3.14159;
string name = "FAB#";
bool ready = true;
int color = #FF8800;    // шестнадцатеричное число начинается с #
int counter;            // без значения: внутри будет 0

age = 21;               // новое значение
age += 1;               // age стала 22
```

Сокращённые формы присваивания:

| Запись | Равносильно |
|---|---|
| `x += 5;` | `x = x + 5;` |
| `x -= 5;` | `x = x - 5;` |
| `x *= 5;` | `x = x * 5;` |
| `x /= 5;` | `x = x / 5;` |
| `x %= 5;` | `x = x % 5;` |

> [!NOTE]
> Если создать числовую или логическую переменную без значения, она получит нулевое значение (`0` или `false`). Со строками так лучше не делать: всегда давай им начальное значение, например `string s = "";`.

### Константы

Слово `const` делает значение неизменным. Константе обязательно нужно сразу дать значение.

```cpp
const int MAX_PLAYERS = 4;
writeln MAX_PLAYERS;      // 4

// MAX_PLAYERS = 10;      // ошибка компиляции: нельзя менять константу
```

### Числа разных типов дружат

Если положить дробное число в целую переменную (или наоборот), компилятор сам всё преобразует:

```cpp
double d = 5;      // станет 5.000000
int n = 3.99;      // станет 3: дробная часть отбрасывается, без округления
```

### Виды значений в коде

| Что | Как выглядит | Примеры |
|---|---|---|
| целое число | цифры | `0`, `42`, `1000` |
| дробное число | цифры с точкой | `3.14`, `0.5` |
| шестнадцатеричное | `#` и цифры/буквы a–f | `#FF`, `#1a2b` |
| логическое | ключевые слова | `true`, `false` |
| строка | в двойных кавычках | `"Hello"` |
| пустое значение | ключевое слово | `null` (превращается в ноль нужного типа) |

### Где «живёт» переменная

Переменная, созданная внутри `{ ... }`, исчезает за закрывающей скобкой.

```cpp
int x = 1;
if x == 1
{
    int y = 2;           // y видна только внутри этих скобок
    writeln x + y;       // 3
}
```

## Операторы

### Арифметика

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` (целое на целое даёт целое) |
| `/` | деление | `7.0 / 2` | `3.5` |
| `%` | остаток от деления | `7 % 2` | `1` |

Когда в выражении встречаются и целые, и дробные числа, результат становится дробным.

Строки умеют складываться: так они склеиваются.

```cpp
string greeting = "Hello, " + "World!";
writeln greeting;        // Hello, World!
```

Унарные операторы: `-x` меняет знак, `+x` ничего не делает, `!flag` переворачивает логическое значение.

### Сравнение

| Оператор | Смысл |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

### Логика

| Оператор | Смысл | Пример |
|---|---|---|
| `&&` | И: верно, если верны обе части | `x > 0 && x < 10` |
| `\|\|` | ИЛИ: верно, если верна хотя бы одна часть | `x < 0 \|\| x > 10` |
| `!` | НЕ: переворачивает значение | `!ready` |

Вычисление «ленивое»: если ответ уже ясен по левой части, правая даже не вычисляется.

### Приоритет операторов

От самого сильного к самому слабому:

| Уровень | Операторы |
|---|---|
| 1 | унарные `-`, `+`, `!` |
| 2 | `*`, `/`, `%` |
| 3 | `+`, `-` |
| 4 | `<`, `>`, `<=`, `>=` |
| 5 | `==`, `!=` |
| 6 | `&&` |
| 7 | `\|\|` |

Не уверен в порядке? Расставь скобки: `(a + b) * c`.

> [!WARNING]
> Оператора возведения в степень `^` в версии 0.1 нет. Для степеней используй функцию `pow` из библиотеки `math`: [Библиотеки и модули](#библиотеки-и-модули). Операторов `++` и `--` тоже пока нет, пиши `i += 1;`.

## Условия

Классическое «если... иначе»:

```cpp
int x = 15;

if x == 15
{
    writeln "ровно пятнадцать";
}
else
{
    writeln "что-то другое";
}
```

Если вариантов больше двух, цепляй `else if`:

```cpp
int score = 72;

if score >= 90
{
    writeln "отлично";
}
else if score >= 60
{
    writeln "хорошо";
}
else
{
    writeln "надо подтянуть";
}
```

Несколько правил:

- Скобки вокруг условия **не обязательны**: можно `if x > 5`, можно `if (x > 5)`.
- Условия можно объединять: `if x > 0 && x < 10`.
- Число тоже работает как условие: `0` означает «ложь», всё остальное «истина».
- Если в ветке одна команда, фигурные скобки можно опустить.

## Циклы

| Цикл | Когда использовать |
|---|---|
| `while` | повторять, пока верно условие |
| `do-while` | то же, но тело выполнится минимум один раз |
| `for` | когда известно, сколько раз повторять |

> [!IMPORTANT]
> В циклах скобки вокруг условия **обязательны**, в отличие от `if`.

### while

```cpp
int i = 0;
while (i < 3)
{
    writeln i;
    i += 1;
}
```

Результат: `0`, `1`, `2`.

### do-while

Сначала действие, потом проверка. Поэтому тело выполнится хотя бы раз, даже если условие с самого начала ложное:

```cpp
int i = 10;
do
{
    writeln i;
    i += 1;
} while (i < 5);
```

Результат: `10`. Обрати внимание на `;` после закрывающей скобки условия.

### for

Три части в скобках: что сделать перед стартом, когда продолжать, что делать после каждого шага.

```cpp
for (int i = 1; i <= 5; i += 1)
{
    writeln i;
}
```

Результат: `1`, `2`, `3`, `4`, `5`.

### break и continue

| Команда | Что делает |
|---|---|
| `break;` | немедленно выходит из цикла |
| `continue;` | пропускает остаток шага и идёт к следующему |

```cpp
int i = 0;
while (true)
{
    i += 1;
    if i % 2 == 0 { continue; }   // чётные пропускаем
    if i > 7 { break; }           // после 7 выходим
    writeln i;
}
```

Результат: `1`, `3`, `5`, `7`.

> [!TIP]
> В цикле `for` команда `continue` не застрянет навечно: она перейдёт к шагу `i += 1`, а не прямо к проверке условия.

## Функции

Функция — это именованный кусок кода, который можно вызывать сколько угодно раз.

```cpp
define имя(тип аргумент1, тип аргумент2) -> типРезультата
{
    // тело
}
```

- `define` объявляет функцию.
- Тип результата пишется после стрелки `->`. Если стрелки нет, функция ничего не возвращает (`void`).
- Результат отдаётся командой `return`.

### Функция без результата

```cpp
define greet(string name)
{
    writeln "Hello, " + name + "!";
}

greet("FAB#");        // Hello, FAB#!
```

### Функция с результатом

```cpp
define square(int x) -> int
{
    return x * x;
}

writeln square(7);    // 49
```

Если тело состоит из одной команды, фигурные скобки не нужны:

```cpp
define twice(int x) -> int
    return x * 2;
```

### Несколько аргументов

```cpp
define cool_print(string label, int value)
{
    writeln label + " готово";
    writeln value;
}

cool_print("Задача", 42);
```

### Рекурсия

Функция может вызывать сама себя:

```cpp
define factorial(int n) -> int
{
    if n <= 1 { return 1; }
    return n * factorial(n - 1);
}

writeln factorial(5);    // 120
```

### Перегрузка

Можно создать несколько функций с одним именем, если у них разные типы аргументов. Компилятор сам выберет подходящую:

```cpp
define show(int x)
{
    writeln x;
}

define show(string s)
{
    writeln "текст: " + s;
}

show(5);          // 5
show("hi");       // текст: hi
```

> [!WARNING]
> Типы аргументов при вызове должны совпадать с объявлением точно. Если есть только `square(int x)`, то вызов `square(2.5)` не сработает: `2.5` это `double`. Объяви версию `square(double x)` или передай `int`.

### Функция main

Есть два способа написать программу:

| Способ | Как это выглядит |
|---|---|
| Без `main` | команды лежат прямо в файле и выполняются сверху вниз |
| С `main` | вся программа живёт внутри `main`, как в больших языках |

```cpp
define main() -> int
{
    writeln "Hello from main!";
    return 0;
}
```

`return 0;` в конце `main` писать необязательно: если забыл, компилятор вернёт `0` сам.

> [!IMPORTANT]
> Если в файле есть `main`, снаружи неё можно оставлять только объявления функций (`define`). Обычные команды вроде `writeln` должны жить внутри функций. Функции нужно объявлять **выше** того места, где их вызываешь.

## Ввод данных

Команда `input_in` читает число с клавиатуры прямо в переменную. Переменную нужно создать заранее.

```cpp
int n;
write "Введи число: ";
input_in n;
writeln n * 2;
```

> [!NOTE]
> В версии 0.1 вводить можно только целые числа (`int`).

## Библиотеки и модули

### Подключение библиотеки

Команда `use` подключает библиотеку. Подключать нужно **до** первого использования её функций.

```cpp
use math;

writeln sqrt(16.0);    // 4.000000
writeln pow(2, 10);    // 1024
writeln floor(3.7);    // 3.000000
writeln round(2.5);    // 3.000000
```

### Библиотека math

| Функция | Аргументы | Результат | Что делает |
|---|---|---|---|
| `pow(x, n)` | `int, int` | `int` | возводит в степень |
| `pow(x, n)` | `long, long` | `long` | возводит в степень |
| `pow(x, n)` | `double, double` | `double` | возводит в степень |
| `sqrt(x)` | `double` или `int` | `double` | квадратный корень |
| `abs(x)` | `int` или `long` | то же | модуль числа |
| `fabs(x)` | `float` или `double` | то же | модуль дробного числа |
| `ceil(x)` | `float` или `double` | то же | округляет вверх |
| `floor(x)` | `float` или `double` | то же | округляет вниз |
| `round(x)` | `float` или `double` | то же | округляет до ближайшего целого |

> [!TIP]
> Тип аргумента выбирает нужную версию функции: `pow(2, 10)` посчитает целое число, а `pow(2.0, 10.0)` дробное. Это та же перегрузка, что и у твоих функций.

### Подключение своего файла

Большую программу можно разложить по файлам. Чтобы подтянуть другой `.fab`-файл, укажи путь в кавычках:

```cpp
use "libs/helpers.fab";
```

Каждый файл подключается один раз, даже если написать `use` несколько раз.

> [!NOTE]
> В версии 0.1 путь в `use "..."` отсчитывается от папки, где лежит сам компилятор, а не от папки со скриптом.

## Мини-проект: FizzBuzz

Пора собрать всё вместе. Классическая задача: пройти числа от 1 до 15 и вывести `Fizz` для кратных 3, `Buzz` для кратных 5 и `FizzBuzz` для кратных обоим.

```cpp
for (int i = 1; i <= 15; i += 1)
{
    if i % 15 == 0
    {
        writeln "FizzBuzz";
    }
    else if i % 3 == 0
    {
        writeln "Fizz";
    }
    else if i % 5 == 0
    {
        writeln "Buzz";
    }
    else
    {
        writeln i;
    }
}
```

Здесь в одной программе работают цикл `for`, цепочка `else if`, остаток от деления `%` и вывод.

**Попробуй сам:**

- Измени границу цикла и сделай FizzBuzz до 100.
- Вынеси проверку в функцию `define label(int n) -> string` и верни из неё нужное слово.
- Выведи сумму всех чисел от 1 до 100 с помощью цикла и переменной-накопителя.

## Шпаргалка

| Что нужно | Как писать |
|---|---|
| Вывод с переводом строки | `writeln выражение;` |
| Вывод без перевода строки | `write выражение;` |
| Переменная | `int x = 5;` |
| Константа | `const int N = 5;` |
| Присваивание | `x = 10;`, `x += 1;` |
| Ввод целого числа | `input_in x;` |
| Условие | `if a > b { ... } else { ... }` |
| Цепочка условий | `else if ... { ... }` |
| Цикл while | `while (условие) { ... }` |
| Цикл do-while | `do { ... } while (условие);` |
| Цикл for | `for (int i = 0; i < n; i += 1) { ... }` |
| Выход из цикла | `break;` |
| Следующий шаг цикла | `continue;` |
| Функция | `define f(int a) -> int { return a; }` |
| Подключить библиотеку | `use math;` |
| Подключить файл | `use "путь/файл.fab";` |
| Комментарии | `// ...` и `/* ... */` |

## Частые ошибки

Компилятор сообщает об ошибках на английском. Вот что они значат:

| Сообщение | Что случилось | Как исправить |
|---|---|---|
| `You miss the ;` | забыта точка с запятой | добавь `;` в конце команды |
| `Variable {x} not found!` | переменная не объявлена или вышла из области видимости | объяви её выше или внутри нужных скобок |
| `Cannot assign to const variable 'x'!` | попытка изменить константу | убери `const` или не меняй значение |
| `'break' outside of a loop!` | `break` вне цикла | используй его только внутри циклов |
| `'continue' outside of a loop!` | `continue` вне цикла | то же самое |
| `Unknown function or overload for codegen: имя` | такой функции нет, либо типы аргументов не подходят | проверь имя, `use` и типы аргументов |
| `Library '...' not found!` | нет файла библиотеки | проверь имя в `use` и папку `lib` рядом с компилятором |
| `Token ... does not match ...` | на месте нужного символа стоит другой | чаще всего забыта скобка, например в `while` |
| `Unknown expression!` | компилятор не понял выражение | проверь опечатки и лишние символы |

## Чего пока нет

Версия 0.1 это только начало. Пока не поддерживаются:

- оператор возведения в степень `^` (используй `pow` из `math`);
- операторы `++` и `--`;
- сравнение строк через `==` и `<`;
- склейка строки с числом (`"x = " + 5`);
- массивы, структуры и классы;
- ввод чисел с дробной частью и строк;
- несколько файлов с общим состоянием за пределами `use "..."`.
