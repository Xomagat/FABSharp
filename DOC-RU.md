## Hello World
``` c++
writeln "Hello World!";
```
 - Также есть команда write, альтернатива writeln только без переноса строки.
``` c++
write "Hello World!\n";
```

 - **Код может меняться, так что это не постоянно!**

## Типизация
|Тип|Размер|Диапозон/Описание| Пример   |
|---|---|---|---|
| `int` | 32 бит | −2 147 483 648 … 2 147 483 647 | `int x = 42;` |
| `double` | 64 бит | ~15–17 значимых цифр | `double d = 3.14159;` |
| `bool` | — | `true` / `false` | `bool b = true;` |
| `string` | — | Строка символов | `string s = "Hello";` |

 - Язык только разрабатывается! *Имена* или *кол-во* типов может **измениться**!

## Условия
``` c++
if condition
{
    // body
}
else
{
    // body
}
```

 - В условиях не обязательны скобки.
 - Также стоит заметить пока не поддерживается команды else if!

### Пример использования:
``` c++
int x = 15;

if x == 15
{
    writeln "true";
}
else
{
    writeln "false";
}
```

 - Условные операторы: ==, !=, <, >, <=, >=, &&(и) и ||(или).

## Арифметика
| Оператор | Описание                      | Пример        |
|-----|-------------------------------|---------------|
| `+` | Оператор сложения             | `4 + 2 == 6`  |
| `-` | Оператор вычитания            | `4 - 2 == 2`  |
| `*` | Оператор умножения            | `4 * 2 == 8`  |
| `/` | Оператор деления              | `4 / 2 == 2`  |
| `^` | Оператор возведения в степень | `4 ^ 2 == 16` |

## Циклы
### While:
 - While - условный цикл
``` c++
while (condition)
{
    // body
}
```
Пример использования:
``` c++
int i = 0;
while (i < 10)
{
    writeln i;
    i = i + 1;
}
```

### For:
 - For - цикл с счетчиком
``` c++
for (initialization; condition; increment)
{
    // body
}
```
Пример использования:
``` c++
for (int i = 0; i < 10; i = i + 1)
{
    writeln i;
}
```

### do-while:
 - do-while - цикл с условием, но он выполниться один раз, даже если условие изначально ложно.
``` c++
do
{
    // body
} while (condition);
```
Пример использования:
``` c++
int i = 1;
do
{
    writeln i;
    i = i + 1;
} while (i <= 5);    // Output: 1, 2, 3, 4, 5
```
``` c++
int i = 1;
do
{
    writeln i;
    i = i + 1;
} while (i <= 0);    // Output: 1
```
 - Так же поддерживаются команды: *continue* и *break*.

## Функции
 - Функции - это заренее прописанные команды, которые можно вызывать во время выполнения программы любое кол-во раз.

Вот так объявляются функции в FAB#:
``` c++
define name(type arg)
{
    // body
}
```
Пример использования:
``` c++
define cool_print(string name, string text)
{
    writeln name + " = " + text;
}

cool_print("2 ^ 8 * 3", 2 ^ 8 * 3); // Output: 2 ^ 8 * 3 = 768.000000
```
``` c++
define pow(double x, double n)
    return x ^ n;

writeln pow(2, 5);  // Output: 32.000000
```
 - Язык только разрабатывается! *Передача аргументов* и *синтаксис* могут *измениться*!
